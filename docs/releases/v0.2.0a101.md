# BreadSched 0.2.0a101

Application version: `0.2.0a101`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha shows direct dated exchange-rate evidence for foreign-currency account balances.

## Highlights

- Ordinary foreign-currency accounts use the latest direct reporting-currency
  quote at or before the valuation date, retaining exact amounts until display.
- GTK and web account views show the quote date and source. When a direct quote
  is missing, they disclose the original ledger currency and do not claim a
  converted amount. Incompatible parent account rollups read "Mixed currencies".
  Cross-report missing-price policy is still being developed.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent book backup. This release makes no schema migration and
does not modify existing transactions or quotes. A build supporting schema 7
can reopen the same book after rollback.

## Verified artifacts

After the full CI matrix passes, the release workflow publishes a source
distribution, a pure-Python wheel, and `SHA256SUMS` from the tested main commit.
