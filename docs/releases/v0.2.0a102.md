# BreadSched 0.2.0a102

Application version: `0.2.0a102`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha tightens the release workflow and local web static-asset boundary.

## Highlights

- CI jobs use read-only repository tokens. Release builds also run without
  write permission; publication validates the tested main commit and the fixed
  artifact names and checksums without running checked-out candidate code.
- The loopback web server serves only its packaged page, script, and stylesheet
  and rejects paths or symlinks outside that set. Financial calculations and
  ledger behavior are unchanged.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent book backup. This release makes no schema migration and
does not modify existing transactions. A build supporting schema 7 can reopen
the same book after rollback.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
