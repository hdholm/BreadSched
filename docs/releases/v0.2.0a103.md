# BreadSched 0.2.0a103

Application version: `0.2.0a103`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha makes account chart and summary currency totals explicit when a direct
reporting-currency quote is missing.

## Highlights

- Account chart rollups and cash and net-worth summaries in GTK, web, and CLI
  present an unavailable total when a nonzero balance lacks a direct quote.
  Web and CLI responses identify accounts requiring quotes.
- When every quote is present, directly converted amounts are summed exactly.
  The selected quote date and source remain visible on individual account rows.
- Dashboard, Plan, Projection, and printed reports have not adopted this aggregate
  valuation contract. Inverse and multi-hop currency paths remain unavailable.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent book backup. This release makes no schema migration and
does not modify existing transactions. A build supporting schema 7 can reopen
the same book after rollback. Existing foreign-currency summaries may now show
an unavailable total until direct quotes are recorded.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
