# BreadSched 0.2.0a104

Application version: `0.2.0a104`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds an exact inverse-pair path for ordinary foreign-currency balances.

## Highlights

- The latest applicable direct currency quote always wins. When none exists,
  BreadSched inverts the latest applicable reverse pair exactly. Account views
  disclose that inverse path along with the source and date of the original quote.
- Account chart and cash/net-worth summaries can use that derived exact amount.
  They remain unavailable if a material component lacks either pair. Security
  prices still need a direct reporting-currency quote.
- Multi-hop exchange paths, staleness cutoffs, and full Dashboard, Plan, Projection,
  and print currency handling remain future work.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent book backup. This release makes no schema migration and
does not modify existing transactions or quotes. An older build supporting schema 7
can reopen the book after rollback, but its summaries will not use inverse pairs.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
