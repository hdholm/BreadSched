# BreadSched 0.2.0a105

Application version: `0.2.0a105`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha makes Dashboard position and liquidity reports disclose missing quotes.

## Highlights

- Configured Dashboard groups show unavailable totals when an included account
  lacks a reporting-currency quote. Affected net worth and liquidity conclusions
  are suppressed in GTK, web, CLI, and the print preview; independent bills and
  expected income remain visible.
- A direct or inverse pair quote can restore the aggregate. Individual account
  notes disclose the selected quote date/source and any inverse rate.
- Plan, Projection, their comparisons, and their printouts still need complete
  currency policy. Multi-hop paths and staleness cutoffs remain unavailable.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent book backup. This release makes no schema migration and
does not modify existing transactions or quotes. A build supporting schema 7
can reopen the same book after rollback, though it may display partial Dashboard
totals when required quotes are missing.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
