# BreadSched 0.2.0a106

Application version: `0.2.0a106`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds browser-selected imports to the loopback web interface.

## Highlights

- Choose a QIF, OFX/QFX, or GnuCash file up to 32 MiB in the web import view.
  The existing server-visible path option remains available.
- Files selected in the browser are retained beside the native book in a
  `<book>.uploads` directory. Re-upload the same filename to refresh the same
  source; use a different filename for an independent source.
- The upload route requires the same loopback token and Host/Origin checks as
  other API requests. The shared import service handles validation and source
  ownership. A failed import restores the previous uploaded file.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent book backup. This release makes no schema migration. The
uploaded source files are separate from the native book: retain the sibling
`<book>.uploads` directory if a remembered upload path must remain usable after
moving the book or rolling back to an older version. Local-path imports remain
compatible with older builds.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
