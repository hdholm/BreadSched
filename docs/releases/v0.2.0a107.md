# BreadSched 0.2.0a107

Application version: `0.2.0a107`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha discloses the age of account valuation quotes.

## Highlights

- GTK, web, and CLI Accounts views show how many days separate a selected
  currency or security quote from the account's valuation date, alongside the
  existing source, date, and inverse-rate evidence.
- Web and CLI account data expose signed quote age. A negative age identifies
  a future-dated quote selected when no as-of date was requested.
- There is no automatic stale-price cutoff. Older eligible quotes remain in use,
  with their age visible for review. Plan and Projection cross-report currency
  conversion remains unfinished.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent book backup. This release makes no schema migration and
does not change saved quotes or transactions. An older build supporting schema 7
can reopen the same book; it may omit the new age disclosure.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
