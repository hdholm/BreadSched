# BreadSched 0.2.0a108

Application version: `0.2.0a108`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha guards scheduled occurrence matching across transaction currencies.

## Highlights

- Planned scheduled occurrences disclose the expected and actual transaction
  currency in event data.
- Resolution suggestions omit schedules whose currency differs from the actual
  transaction. A previously linked cross-currency occurrence has no numeric
  occurrence variance; neither amount is converted.
- Plan period totals, scenario estimates, and Projection still need complete
  currency valuation and missing-quote behavior.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent book backup. This release makes no schema migration or
transaction rewrite. Older schema 7 builds can reopen the book, but may suggest
cross-currency matches that this release suppresses.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
