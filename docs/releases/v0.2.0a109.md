# BreadSched 0.2.0a109

Application version: `0.2.0a109`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha preserves distinct imported commodity identities when their mnemonics
collide across namespaces.

## Highlights

- GnuCash security and currency commodities with the same mnemonic remain
  separate. Re-import reuses the matching namespace and mnemonic pair.
- Existing CURRENCY and ISO4217 currency definitions with the same mnemonic may
  share one currency. An ambiguous bare mnemonic in a price is warned about and
  left unresolved rather than assigned to an arbitrary commodity.
- Cross-report currency valuation and broader source mapping remain under
  development.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Back up the native book before refreshing an imported source. This release does
not rewrite existing commodities or repair a previously misidentified imported
holding automatically. Review such holdings and their imported quotes after
re-import. Older schema 7 builds can reopen the book, but may conflate matching
mnemonics again on later imports.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
