# BreadSched 0.2.0a110

Application version: `0.2.0a110`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha establishes a shared exact write contract for manually supplied
currency quotes. Rate-entry controls remain future work.

## Highlights

- A valid source/target currency pair and positive exact rate can be saved as a
  BreadSched-owned dated quote without overwriting imported quote evidence.
- Repeated entry on the same date and pair updates the manual quote; undo
  restores the preceding quote value. An imported quote on that date remains.
- The existing as-of conversion selects the rate with its date and provenance.
  GTK, web, and CLI do not yet provide a manual exchange-rate entry control.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent book backup. This release does not migrate or rewrite
existing books. Older schema 7 builds can reopen a book; quote selection remains
subject to the rate data present in that book.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
