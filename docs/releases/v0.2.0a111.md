# BreadSched 0.2.0a111

Application version: `0.2.0a111`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds command-line entry of manual foreign-exchange rates for currencies
already in a book. GTK and web controls remain future work.

## Highlights

- `breadsched rate BOOK --from EUR --to USD --date YYYY-MM-DD --value 1.25`
  saves a directional target-units-per-source-unit quote.
- Exact rational values, date, source, and handle are available with `--json`.
  Repeating a same-day manual entry updates its own record while preserving
  imported quotes. Ambiguous currency codes require an exact handle.
- As-of account conversion continues to disclose the selected quote and missing
  quote cases. Plan and Projection cross-currency totals remain incomplete.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent book backup. This release does not migrate existing books.
Older schema 7 builds can reopen a book; manual quotes already written remain
book data, although their entry interfaces differ.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
