# BreadSched 0.2.0a112

Application version: `0.2.0a112`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds manual exchange-rate entry in the web Accounts view for currencies
already in a book. GTK entry remains future work.

## Highlights

- Select a dated source and target currency, then enter exact target units per
  source unit. The web write uses the same shared contract as CLI rate entry.
- Invalid requests do not change stored quotes. A repeated same-day manual
  quote updates its own record without replacing imported quote evidence.
- Account values continue to show the chosen quote date and source or a
  missing-quote warning. Plan and Projection cross-currency totals remain open.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent book backup. This release does not migrate existing books.
Older schema 7 builds can reopen a book; manually entered quotes remain book
data even when an older interface cannot enter them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
