# BreadSched 0.2.0a113

Application version: `0.2.0a113`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha makes an ungrouped Dashboard's Net worth reflect the complete ledger
valuation and explains when emergency coverage cannot yet be calculated.

## Highlights

- Before Dashboard groups are configured, Net worth values all ledger assets and
  liabilities as of the displayed date. Missing exchange or security quotes
  leave the total unavailable instead of combining unlike currencies.
- Grouped asset and debt totals remain unconfigured until accounts are selected.
  A configured selection can still cover only part of the household book.
- With no committed outgoings, the emergency fund and months covered show a
  missing-commitments explanation in GTK, web, CLI, and printed reports.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent book backup. This version does not migrate existing books.
Older schema 7 builds can reopen them; their Dashboard may again show an
unconfigured zero until groups and schedules are set up.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
