# BreadSched 0.2.0a114

Application version: `0.2.0a114`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds a separate synthetic book for learning without using personal
financial records.

## Highlights

- Run `breadsched sample PATH` to create invented accounts, dated balanced
  transactions, Dashboard groups, recurring commitments, a Plan estimate, and a
  Base scenario. The command refuses an existing path.
- `--as-of YYYY-MM-DD` anchors the example to a chosen month so the account
  names, event dates, amounts, and financial results can be reproduced. Book
  object handles are generated normally and can differ across runs.
- Open the file in GTK or web and review the next month's Plan; no tutorial data
  is written into an existing household book.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent backup of any real book. This version does not migrate
existing books, and older schema 7 builds can reopen a generated sample.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
