# BreadSched 0.2.0a116

Application version: `0.2.0a116`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds a dated remaining-spending view to Expense Explorer.

## Highlights

- Remaining is the selected period's expense plan minus actual spending posted
  through the report's as-of date. Refunds increase it and overspending is negative.
- Parent categories and section totals count child activity once. Future-only
  periods and unconverted foreign-currency expense activity explain why a remaining
  value is unavailable.
- GTK, web, and printable Expense Explorer views show the same result. Rollover is
  not enabled; the existing full-period Actual and Variance cells remain separate.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate books;
older schema 7 builds can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
