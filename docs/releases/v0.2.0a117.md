# BreadSched 0.2.0a117

Application version: `0.2.0a117`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds optional expense-period rollover to Expense Explorer.

## Highlights

- Turn on **Carry prior periods** to add a completed period's surplus or deficit
  to the next selected period. The first period opens at zero carry.
- Each period shows its opening carry, plan, actual through as-of, and remaining
  amount in GTK, web, and print. An unavailable prior currency period blocks later
  carry rather than inventing a value.
- The toggle is a read-only view choice. It does not change the book or create a
  separate monthly budget ledger.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate books;
older schema 7 builds can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
