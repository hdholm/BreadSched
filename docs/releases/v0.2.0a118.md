# BreadSched 0.2.0a118

Application version: `0.2.0a118`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds a first Flatpak build input and CI sandbox command smoke test.

## Highlights

- A GNOME-runtime manifest builds BreadSched into the Flatpak application prefix.
- CI checks the packaged command-line version and GTK launcher help inside the
  sandbox. The full file, recovery, help, print, and offline workflows still need
  validation before a Flatpak installer is offered to users.
- This release continues to distribute the wheel and source archive; it does not
  include a Flatpak or Windows installer.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate books;
older schema 7 builds can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
