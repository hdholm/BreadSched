# BreadSched 0.2.0a119

Application version: `0.2.0a119`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha keeps statements reconciled in BreadSched intact across GnuCash
re-import and adds a batched review of GnuCash changes to those transactions.

## Highlights

- A split reconciled in BreadSched keeps its Reconciled state and statement date
  when a GnuCash book is re-imported, so completed statements stay valid and can
  be reopened.
- If GnuCash changes the date, description, number, or currency of such a
  transaction, or a reconciled split's account, amount, quantity, memo, or action,
  re-import leaves it unchanged and holds the GnuCash version for review.
- The review offers Keep BreadSched version, Use GnuCash version, or Decide later
  for each held change and applies the batch as one undo step. GTK offers it when
  a book opens and after an import; the web interface and the new
  `breadsched import-review` command provide the same decisions.
- Imported transactions with no split reconciled in BreadSched are still
  refreshed from GnuCash as before.

## Native-book compatibility

No data-format change was made. Held GnuCash versions are stored in existing book
metadata. Schema 7 books open directly; the supported native compatibility window
remains schemas 6–7.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate books;
older schema 7 builds can reopen them, but they ignore held GnuCash versions and
will overwrite reconciled imported transactions on their next re-import.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
