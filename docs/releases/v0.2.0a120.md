# BreadSched 0.2.0a120

Application version: `0.2.0a120`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha completes the first-run Dashboard review for imported books that hold
securities, loans, and credit cards.

## Highlights

- A credit card that owes a balance but has no payment day or payment schedule is
  now disclosed with a “Card payments not set up” note, instead of silently adding
  nothing to Needed within 30 days.
- When no income is scheduled, next income reports “No scheduled income” rather
  than a missing reporting-currency quote.
- Printed Dashboard reports include coverage notes even before Dashboard groups
  are configured.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate books;
older schema 7 builds can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
