# BreadSched 0.2.0a121

Application version: `0.2.0a121`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds desktop integration for the Flatpak build and validates the GTK
interface inside the sandbox.

## Highlights

- A locally built Flatpak installs a desktop menu entry, software-centre
  (AppStream) metadata, and an application icon; GTK windows use the same icon.
- CI opens a book, every view, and the User Guide in the sandboxed GTK interface
  with the network unshared, and checks that settings persist in the sandbox.
- No Flatpak installer is published yet. File-chooser portals and printing inside
  the sandbox still need validation. The wheel and source archive remain the
  supported release artifacts.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate books;
older schema 7 builds can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
