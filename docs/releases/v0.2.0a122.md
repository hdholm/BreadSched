# BreadSched 0.2.0a122

Application version: `0.2.0a122`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha makes missed scheduled transactions readable on the Dashboard.

## Highlights

- A schedule with several missed dates now appears once on the Dashboard, with the
  missed date range, count, total, and how often it recurs, instead of one identical
  row per missed date.
- Monthly and annual figures describe the schedule once. Each missed date and
  amount is still available in the web interface, printed report, and
  `breadsched dashboard --json`.
- The command line and web interface show a plain frequency such as “every month”
  instead of an internal cycle value such as `1.0000`.
- Liquidity and emergency figures are unchanged; every missed occurrence still
  counts until it is posted or skipped.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate books;
older schema 7 builds can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
