# BreadSched 0.2.0a123

Application version: `0.2.0a123`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds a reviewed, duplicate-safe batch for due and missed scheduled
transactions.

## Highlights

- Due and missed scheduled transactions are reviewed in one batch, grouped by
  schedule with a count and total. Each date can be posted, skipped (marked as
  done), or left for later, and a schedule with several dates can be decided at once.
- Before anything is written, every chosen date is checked again. If one was
  already posted or skipped in another window, the browser, or the command line,
  nothing is written and the review explains why, so nothing is posted twice.
- The whole batch is one undo step. Plan-only estimates are never offered for
  posting.
- The web interface no longer posts everything due in one click; its Scheduled
  and Dashboard buttons open the review. The command line adds `breadsched
  due-review`.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate books;
older schema 7 builds can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
