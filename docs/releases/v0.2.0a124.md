# BreadSched 0.2.0a124

Application version: `0.2.0a124`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds manual exchange-rate entry to the desktop application.

## Highlights

- Accounts has an **Exchange rate…** button. Choose the currency to convert from
  and to (the reporting currency by default), the quote date, and the number of
  target-currency units per one source-currency unit.
- The dialog shows the latest recorded quote for the chosen pair. It saves
  through the same rules as the web interface and `breadsched rate`. An invalid
  date, rate, or currency pair is refused and nothing is saved.
- Manual quotes never change imported quotes or ledger amounts. Accounts continue
  to show the quote date and source used, or a missing-quote warning.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate books;
older schema 7 builds can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
