# BreadSched 0.2.0a126

Application version: `0.2.0a126`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha extends exchange-rate conversion from Plan to Projection.

## Highlights

- Projection converts schedules, estimates, and scenario events in another
  currency with the exchange rate known the day before the projection starts.
  A reverse rate is inverted when no direct rate exists.
- Accounts in another currency open at their converted value. Without a rate,
  their balance is left out rather than counted as reporting currency.
- Projection warnings state the rate, its date and source, and whether it was
  inverted, or list each amount and balance left out. The warnings appear in
  GTK, the web interface, the command line, and print.
- Scenario comparisons compare the converted projections.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate books;
older schema 7 builds can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
