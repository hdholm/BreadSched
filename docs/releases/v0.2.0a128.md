# BreadSched 0.2.0a128

Application version: `0.2.0a128`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds CSV statement import from the command line.

## Highlights

- `breadsched import-csv` imports a bank or card statement saved as CSV into the
  account you choose. You say which columns hold the date, the amount (or debit
  and credit), and optionally the description and memo.
- `--preview` shows every row before anything is written: new, already imported,
  possible duplicate, or invalid with the line number and reason.
- Encoding, delimiter, date order, and decimal separator are detected from the
  whole file. If the date order cannot be told apart, you are asked to choose it.
- Importing the same statement again adds nothing and keeps any categories you
  chose since. A row that matches a transaction already in the account on the
  same date and amount is held back unless you include it.
- The whole import is one undo step.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate books;
older schema 7 builds can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
