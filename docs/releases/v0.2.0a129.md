# BreadSched 0.2.0a129

Application version: `0.2.0a129`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha fixes OFX and QIF re-import undoing categories you chose (issue #129).

## Highlights

- Importing the same OFX/QFX or QIF statement again no longer moves a transaction
  you categorized back to **Uncategorized**. Only the bank account's side of each
  transaction is refreshed from the file.
- If the bank corrects an amount, a transaction with one category keeps that
  category at the new amount. A transaction you split across several categories
  is left as it is, with a warning to review it.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate books;
older schema 7 builds can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
