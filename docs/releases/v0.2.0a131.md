# BreadSched 0.2.0a131

Application version: `0.2.0a131`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds CSV statement import to the web interface.

## Highlights

- The web **Import** view has a **CSV statement** section. Choose the file (or
  enter a path) and select **Read columns** to see how it was read and its first
  rows; BreadSched suggests which column holds the date, amount, description, and
  memo.
- Choose the account and any options, then **Preview** every row: new, already
  imported, possible duplicate, or invalid with the reason. Nothing is written
  until **Import**, and the whole import is one undo step.
- It follows the same rules as `breadsched import-csv`: re-importing adds
  nothing and keeps your categories, and possible duplicates are held back unless
  included.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate books;
older schema 7 builds can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
