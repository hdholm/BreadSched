# BreadSched 0.2.0a132

Application version: `0.2.0a132`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds CSV statement import to the desktop application.

## Highlights

- **File → Import CSV Statement…** opens a dialog for a bank or card statement
  saved as CSV. Choose the file and BreadSched shows its first rows and suggests
  which columns hold the date, amount, description, and memo.
- Choose the account and any options, then **Preview** every row: new, already
  imported, possible duplicate, or invalid with the reason. **Import** writes the
  rows as one undo step.
- The rules match the web interface and `breadsched import-csv`: importing the
  same statement again adds nothing and keeps your categories.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate books;
older schema 7 builds can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
