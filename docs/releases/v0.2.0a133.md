# BreadSched 0.2.0a133

Application version: `0.2.0a133`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds transfer review to CSV statement import.

## Highlights

- Money moved between two of your accounts shows up on both statements. When you
  import the second statement, a row with the opposite amount of an uncategorized
  transaction already imported into another account within three days is marked
  **possible transfer**, with that account and date.
- Choose **Link possible transfers** in the web Import view or the desktop Import
  CSV Statement dialog, or add `--link-transfers` to `breadsched import-csv`, to
  turn each pair into one transfer. Otherwise the row is imported as new and
  nothing already in the book changes.
- A transaction you have already categorized is never offered. Re-importing a
  linked statement adds nothing, and the whole import is still one undo step.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate books;
older schema 7 builds can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
