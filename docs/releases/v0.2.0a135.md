# BreadSched 0.2.0a135

Application version: `0.2.0a135`

Native schema version: `8`

Supported native schemas: `6–8`

This alpha adds payee screens to the desktop and web interfaces.

## Highlights

- **Actions → Payees…** in the desktop application and the **Payees** view in
  the web interface list your payees with how many transactions each has.
- Add a payee with a name and example descriptions, or edit one to rename it or
  change its descriptions. Deleting a payee clears it from its transactions; the
  descriptions themselves are never changed.
- **Proposals** lists transactions without a payee whose description matches,
  with the matched text. Uncheck any you do not want, then **Accept selected**;
  a transaction that already has a payee is never changed.

## Native-book compatibility

No data-format change was made. Schema 8 books open directly; schemas 6 and 7
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
8 books; 0.2.0a134 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
