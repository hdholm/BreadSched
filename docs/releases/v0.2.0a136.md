# BreadSched 0.2.0a136

Application version: `0.2.0a136`

Native schema version: `8`

Supported native schemas: `6–8`

This alpha shows payees in the register and lets you set them while editing.

## Highlights

- The desktop register has a **Payee** column, and its filter also matches payee
  names.
- The desktop transaction editor has a **Payee** choice; choose **(no payee)** to
  clear it. Descriptions are never changed.
- In the web register, each row has a **Payee** list that saves as soon as you
  choose.

## Native-book compatibility

No data-format change was made. Schema 8 books open directly; schemas 6 and 7
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
8 books; 0.2.0a134 and 0.2.0a135 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
