# BreadSched 0.2.0a137

Application version: `0.2.0a137`

Native schema version: `8`

Supported native schemas: `6–8`

This alpha fixes a desktop Dashboard layout problem.

## Fixes

- A Dashboard group that combines several accounts could make the desktop
  window wider than the screen, because the group's note lists every account's
  quote details (#140). The line is now shortened with "…" and the full text
  appears when you hover over it. Long notes in the headline cards wrap instead
  of widening the window.

## Native-book compatibility

No data-format change was made. Schema 8 books open directly; schemas 6 and 7
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
8 books; 0.2.0a134 through 0.2.0a136 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
