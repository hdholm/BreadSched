# BreadSched 0.2.0a138

Application version: `0.2.0a138`

Native schema version: `8`

Supported native schemas: `6–8`

This alpha adds reviewed categorization rules on the command line.

## Highlights

- `breadsched rules` keeps an ordered list of rules. Each rule matches a payee
  or a description and names an income or expense category.
- `--preview` shows a proposed category for each imported transaction still in
  **Uncategorized CSV** or **Uncategorized OFX**, which rule decided it, and any
  later rule that would have chosen something else.
- Nothing changes until you accept (`--accept-all` or `--accept TRANSACTION`),
  and accepting is one undo step. A category you already chose is never
  replaced, and transactions split across several uncategorized lines are left
  for you.

## Native-book compatibility

No data-format change was made; rules are stored in the book's metadata. Schema
8 books open directly, and schemas 6 and 7 still migrate automatically with a
verified backup. Earlier 0.2.0a134–a137 builds can open a book with rules and
ignore them.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
8 books.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
