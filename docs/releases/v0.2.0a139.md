# BreadSched 0.2.0a139

Application version: `0.2.0a139`

Native schema version: `8`

Supported native schemas: `6–8`

This alpha adds categorization-rule screens to the desktop and web interfaces.

## Highlights

- **Actions → Categorization Rules…** in the desktop application and the
  **Rules** view in the web interface list your rules in priority order.
- Add a rule that matches a description or a payee and names a category; move
  rules up or down to change which one decides; delete one you no longer need.
- **Proposals** shows each uncategorized imported transaction's proposed
  category, the rule that decided it, and any later rule that would have chosen
  differently. Uncheck any you do not want, then **Accept selected**. A category
  you already chose is never replaced.

## Native-book compatibility

No data-format change was made. Schema 8 books open directly; schemas 6 and 7
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
8 books; 0.2.0a134 through 0.2.0a138 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
