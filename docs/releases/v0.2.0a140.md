# BreadSched 0.2.0a140

Application version: `0.2.0a140`

Native schema version: `8`

Supported native schemas: `6–8`

This alpha adds entry autocomplete to register quick entry.

## Highlights

- In the desktop and web register, type a description in quick entry and move
  on: if an earlier transaction in that account has a matching description, its
  other account and amount are filled in, with a note saying where they came
  from and which button would repeat it.
- Matching ignores case, punctuation, and words containing digits such as store
  numbers, the same way payees and categorization rules match.
- An amount you already typed is never replaced, nothing is posted until you
  choose a button, and notes, reconciliation, planning links, and FSA claims are
  never copied.

## Native-book compatibility

No data-format change was made. Schema 8 books open directly; schemas 6 and 7
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
8 books; 0.2.0a134 through 0.2.0a139 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
