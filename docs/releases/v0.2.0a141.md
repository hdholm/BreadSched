# BreadSched 0.2.0a141

Application version: `0.2.0a141`

Native schema version: `8`

Supported native schemas: `6–8`

This alpha adds entry autocomplete to the desktop transaction editor.

## Highlights

- In the desktop transaction editor, start a new transaction and leave the
  description or choose a payee: if an earlier transaction matches, all of its
  splits (accounts, amounts, and memos) are filled in, along with its payee if you
  have not chosen one, and a note says where they came from.
- The editor proposes only while no split has an amount or memo yet, so nothing
  you typed is replaced. Nothing is saved until you choose **Save**, and editing
  an existing transaction never proposes anything.

## Native-book compatibility

No data-format change was made. Schema 8 books open directly; schemas 6 and 7
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
8 books; 0.2.0a134 through 0.2.0a140 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
