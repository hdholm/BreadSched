# BreadSched 0.2.0a142

Application version: `0.2.0a142`

Native schema version: `8`

Supported native schemas: `6–8`

This alpha cleans up the desktop chrome: navigation, spacing, color, and numeric margins.

## Highlights

- The icon toolbar no longer repeats Plan, Accounts, and Projection as separate
  buttons pointing at the sidebar's own categories; category navigation now lives
  in exactly one place.
- The sidebar starts narrower, since it no longer needs to match a wider toolbar
  duplicate; the extra width goes to the view. It is still a resizable panel.
- Every register/report table (register, accounts, dashboard, scheduled,
  upcoming) shares a `data-table` style with a subtle background on every other
  row, so rows can be told apart without hovering.
- Numeric values, including the Plan grid's, keep a small margin from their
  column's or pane's edge instead of sitting flush against it.
- The register's dialog button is now labeled for what it is actually for
  (extra splits, notes, or reconciliation); an ordinary two-split transaction
  already posts directly from the register's quick entry with no dialog.

## Native-book compatibility

No data-format change was made. Schema 8 books open directly; schemas 6 and 7
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
8 books; 0.2.0a134 through 0.2.0a141 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
