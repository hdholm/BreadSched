# BreadSched 0.2.0a143

Application version: `0.2.0a143`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha adds reimbursable expenses and receivables (engine, service, and CLI).

## Highlights

- Track an expense and what an insurer, employer, or other payer is expected to
  reimburse as linked but distinct facts: the original expense is never rewritten
  or erased, and a reimbursement is never counted as new income.
- Status -- open, partially reimbursed, disputed, written off, or settled -- is
  always recomputed from the linked ledger splits plus any recorded dispute or
  write-off, so it can never drift from the book.
- `breadsched receivables` adds a receivable, links the expense and reimbursement
  splits, records a dispute or a write-off, deletes a receivable, and lists every
  receivable with its age, expected cash date, and current standing.
- A GnuCash re-import that would delete a transaction a receivable depends on is
  refused, the same protection FSA claims already have.
- Desktop and web screens for receivables are not part of this alpha; they come in
  a later release.

## Native-book compatibility

Native schema advances from 8 to 9: a new `receivable` table is added. Schema 9
books open directly; schemas 6, 7, and 8 still migrate automatically with a
verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version migrates schema 6, 7, and
8 books to schema 9 on first open; earlier alphas (0.2.0a134 through 0.2.0a142)
cannot reopen a schema 9 book afterward.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
