# BreadSched 0.2.0a144

Application version: `0.2.0a144`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha makes Dashboard totals independent of Dashboard groups.

## Highlights

- Net worth, Assets, and Debts always include every asset and liability account,
  and Liquid every cash-like account, whether or not Dashboard groups are
  configured. Groups now only arrange accounts into rows.
- Changing groups never changes the totals, near-term needs, Months covered, or
  the pending bills and income lists, so the "Partial Dashboard groups" coverage
  notes are gone. The note about credit cards without payment setup remains.
- Assets and Debts are shown even before any group is configured.
- The README no longer repeats the Expense Explorer and Dashboard walkthrough; see
  the User Guide.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
