# BreadSched 0.2.0a147

Application version: `0.2.0a147`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha reorganizes the desktop Dashboard and table column choosers.

## Highlights

- The desktop Dashboard shows account groups, pending bills, and expected income
  as separate cards, each only as wide as its columns, side by side when the window
  has room.
- Each table's column chooser now sits in that table's own heading, and its tooltip
  names the table, instead of sharing the view's toolbar.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a146 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
