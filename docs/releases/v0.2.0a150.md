# BreadSched 0.2.0a150

Application version: `0.2.0a150`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha moves desktop view commands into menus and toolbar icons.

## Highlights

- Each view's commands are in the Actions menu under the view's name; common
  ones are toolbar icons while that view is shown.
- Accounts has no button row: New/Edit Account, Security Price, and Exchange Rate
  are toolbar icons, and Hide Empty / Show Hidden Accounts are View menu items.
- Manage FSA Claims is a toolbar icon on the FSA Dashboard, and Configure
  Dashboard Groups replaces the Dashboard's "Accounts…" button.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a149 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
