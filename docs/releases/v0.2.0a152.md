# BreadSched 0.2.0a152

Application version: `0.2.0a152`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha replaces desktop quick entry with a blank entry row at the bottom of
the register.

## Highlights

- Type a new transaction directly into the register's last row. Enter saves it,
  Tab and Shift+Tab move between fields, and Escape clears it.
- Leaving the description fills only untouched fields from the latest matching
  entry. **Split…** opens the full editor prefilled with the row.
- Switching accounts, opening another transaction, or closing a register window
  with a half-typed row asks whether to save or discard it.
- The browser interface keeps its quick-entry form for now.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a151 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
