# BreadSched 0.2.0a153

Application version: `0.2.0a153`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha moves more desktop view commands to the toolbar.

## Highlights

- Scheduled (New Scheduled, Suggest, New Loan), Plan (New Scenario, Scenarios,
  Explore), and Projection (Compare, Export) commands are toolbar icons while
  their view is shown, and remain in the Actions menu.
- Buttons whose state follows the view, the Register's own buttons, and buttons
  that act on a selected row stay in their views.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a152 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
