# BreadSched 0.2.0a154

Application version: `0.2.0a154`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha lets the desktop register's blank row hold a split transaction.

## Highlights

- **Split** at the end of the blank row opens one line per split, with a memo,
  account, and amount each, plus a live imbalance line.
- Enter saves only a balanced transaction with a split in the register's account.
- A matching earlier multi-split entry fills the lines, and two lines fold back
  into the ordinary row.
- The pencil icon opens the full editor with every line.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a153 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
