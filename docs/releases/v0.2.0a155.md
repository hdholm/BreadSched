# BreadSched 0.2.0a155

Application version: `0.2.0a155`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha fixes a split consistency defect when a transaction's amount is edited.

## Highlights

- Editing an existing split's amount now updates its stored account quantity too,
  where before the quantity kept the old amount (#166). Displayed totals were
  unaffected.
- Editing a split that an earlier version left mismatched brings its quantity back
  in line.
- A split in an account held in another commodity is refused with a clear message
  instead of being saved with a mismatched quantity.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a154 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
