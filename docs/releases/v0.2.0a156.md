# BreadSched 0.2.0a156

Application version: `0.2.0a156`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha lets desktop register rows be edited in place.

## Highlights

- Select a transaction and press F2 (or **Actions → Register → Edit Transaction in
  Place**) to edit it in its own row, with split lines for a transaction with more
  than two splits.
- Enter saves and Escape cancels. Leaving a changed edit asks whether to save it.
- Details the row does not show (notes, planning purposes, investment
  classifications, reconciliation, FSA links) and each split's identity are kept.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a155 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
