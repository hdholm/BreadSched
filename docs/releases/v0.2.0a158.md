# BreadSched 0.2.0a158

Application version: `0.2.0a158`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha brings the desktop register's blank row, split lines, and in-place
editing to the browser.

## Highlights

- The browser register has a blank row at the bottom; Enter saves a new entry.
- **Split** gives one line per split with a live imbalance line.
- **Edit** changes any row in place and keeps the details the row does not show.
- The register shows the account's own two headings instead of one signed column.
- Amounts are sent as exact fractions, so a comma-decimal browser is read
  correctly.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a157 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
