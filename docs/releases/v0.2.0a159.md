# BreadSched 0.2.0a159

Application version: `0.2.0a159`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha adds a desktop screen for reimbursable expenses.

## Highlights

- **Actions → Reimbursable Expenses…** lists, adds, and changes receivables, with
  recomputed status, age, and remaining balance.
- Link expense and reimbursement splits, record disputes, and write off balances
  without changing any transaction.
- **Track as Reimbursable…** in a register starts a receivable from the selected
  expense.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a158 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
