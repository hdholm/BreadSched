# BreadSched 0.2.0a161

Application version: `0.2.0a161`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha proposes reimbursement links for credits that clearly pay back a
receivable.

## Highlights

- A credit in the same expense account and currency, dated on or after the
  expense, and no more than what is still owed is proposed for review.
- If several receivables fit, the payer must be named in the description.
- Nothing links until you accept, on the desktop, in the browser, or with
  `breadsched receivables --accept-proposals`.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a160 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
