# BreadSched 0.2.0a163

Application version: `0.2.0a163`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha imports security prices from QIF and OFX files.

## Highlights

- QIF price lists and OFX investment statement prices are recorded for securities
  already in the book.
- Prices for unknown securities or currencies are reported as skipped; nothing is
  invented.
- Re-importing updates prices in place, and an imported price never replaces one
  entered in BreadSched.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a162 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
