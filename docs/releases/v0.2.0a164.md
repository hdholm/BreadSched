# BreadSched 0.2.0a164

Application version: `0.2.0a164`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha records OFX per-transaction exchange rates as dated quotes.

## Highlights

- An OFX transaction's `CURRATE` is saved as that day's exchange quote (source
  `ofx`), like a manual exchange rate.
- Foreign-currency (`CURRENCY`) amounts are posted converted into the account's
  currency; a transaction without a usable rate is reported as skipped.
- Re-importing refreshes the same quote rather than adding another.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a163 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
