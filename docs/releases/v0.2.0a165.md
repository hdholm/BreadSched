# BreadSched 0.2.0a165

Application version: `0.2.0a165`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha values securities that are quoted only in another currency.

## Highlights

- A security's foreign-currency price is converted once with the exchange rate in
  effect on the same date; a reporting-currency price still takes precedence.
- GTK, browser, CLI, and Dashboard evidence names both quotes' dates and sources.
- Without the exchange rate, the value stays in the quote currency and out of
  totals, and says so.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a164 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
