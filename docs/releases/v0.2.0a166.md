# BreadSched 0.2.0a166

Application version: `0.2.0a166`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha adds spending over time to Expense Explorer.

## Highlights

- A chart of total planned and actual spending for each Plan period, in GTK and
  the browser, with the as-of boundary marked.
- A per-period split of actual spending across top-level categories that sums
  exactly to the total, also in the printout.
- Clicking a period selects it for the category comparison and merchant detail.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a165 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
