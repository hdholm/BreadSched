# BreadSched 0.2.0a167

Application version: `0.2.0a167`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha imports OFX investment transactions.

## Highlights

- Brokerage OFX/QFX statements import buys, sells, reinvestments, income,
  expenses, and cash activity as balanced transactions with security quantities.
- Securities match by ticker or are created from the statement's security list;
  re-import refreshes without duplicates and keeps your recategorizations.
- Option trades, share transfers, splits, and similar records are reported as
  skipped.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a166 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
