# BreadSched 0.2.0a170

Application version: `0.2.0a170`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha adds category, payee, and currency columns to CSV import.

## Highlights

- A CSV category column posts rows to existing accounts; unknown or ambiguous
  names make the row invalid instead of creating accounts.
- A payee column sets payees you already have; unknown payees are noted.
- A currency column refuses rows in a currency other than the account's.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a169 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
