# BreadSched 0.2.0a174

Application version: `0.2.0a174`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha writes simple changes back to a GnuCash SQLite book (#174).

## Highlights

- `breadsched gnucash-writeback` previews exactly what would be written, then
  writes only the transactions you choose.
- New two-split transactions, text and date edits, and reconcile marks are
  supported; everything else is listed and left alone.
- A backup (with configurable retention), one atomic write, read-back and
  round-trip verification, and automatic restore protect the book; changes you
  did not choose are left as they are.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a173 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
