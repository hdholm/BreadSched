# BreadSched 0.2.0a177

Application version: `0.2.0a177`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha splits the user guide by interface (#181).

## Highlights

- An interface-neutral overview explains what each feature does and its rules;
  desktop, browser, and command-line parts give the steps and link back to it.
- Every interface shows every part: the desktop guide window switches parts and
  follows links, the browser has a **Guide** page, and `breadsched guide` prints
  any part.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a176 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
