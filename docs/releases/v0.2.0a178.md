# BreadSched 0.2.0a178

Application version: `0.2.0a178`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha arranges the desktop toolbar and Actions menu around the current view
(#182).

## Highlights

- The toolbar names the current view and shows its commands next to the general
  commands; the current view's own icon is hidden, and the account and
  transaction counts follow the icons on two stacked lines.
- The Actions menu lists the current view's commands first and every other view's
  under Other Views.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a177 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
