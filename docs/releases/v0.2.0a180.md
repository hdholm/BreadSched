# BreadSched 0.2.0a180

Application version: `0.2.0a180`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha builds and tests a per-user Windows installer in CI.

## Highlights

- `packaging/windows/` builds an NSIS installer with its own Python and GTK
  runtime; no administrator rights or separate Python are needed.
- CI installs it on a clean Windows runner, runs the command line and desktop
  smoke from the installed copy, reinstalls over it, and uninstalls it while
  keeping books. The installer is a workflow artifact, not yet a release asset.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a179 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
