# BreadSched 0.2.0a182

Application version: `0.2.0a182`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha repairs the release workflow, which had not published a release since
0.2.0a133 (#207).

## Highlights

- The release wheel check compares the installed `breadsched --version` line with the
  tested source instead of a hard-coded schema window that went stale at schema 8.
- This is the first published alpha since 0.2.0a133; see the changelog for the
  versions in between.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a181 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, and `SHA256SUMS` for the tested commit.
