# BreadSched 0.2.0a183

Application version: `0.2.0a183`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha is the first release since 0.2.0a133 (#207) and the first with a
Windows installer.

## Highlights

- `BreadSched-0.2.0a183-setup.exe` installs per user with its own Python and GTK;
  the release workflow built, installed, exercised, and uninstalled it on Windows
  from this commit. It is not yet code-signed, so check it against `SHA256SUMS`.
- The release workflow publishes again: its wheel check follows the native schema
  instead of a window that went stale at schema 8.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a182 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, and `SHA256SUMS` for the
tested commit.
