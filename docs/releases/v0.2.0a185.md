# BreadSched 0.2.0a185

Application version: `0.2.0a185`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha lets the Windows installer put the command line on `PATH`.

## Highlights

- The Windows installer can add the `breadsched` command to your own `PATH`: tick
  the option on its Components page (off by default) or pass `/ADDTOPATH` to a
  silent install. Later installs keep the choice, and uninstalling removes the
  entry while leaving the rest of `PATH` exactly as it was.
- The local browser server now reads the body of a write it rejects before
  answering, so the connection is not reset and Windows browsers receive the
  error response.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a184 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, and `SHA256SUMS` for the
tested commit.
