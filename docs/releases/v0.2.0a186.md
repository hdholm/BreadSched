# BreadSched 0.2.0a186

Application version: `0.2.0a186`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha checks the Windows file chooser and printing in the installed copy.

## Highlights

- Before release, the Windows installer is now also checked with the native file
  chooser and printing. The installed copy opens a book chosen in the native
  Open dialog, saves an export through the native save dialog, and opens each
  printable report in the default application.
- No application behavior changed.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a185 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, and `SHA256SUMS` for the
tested commit.
