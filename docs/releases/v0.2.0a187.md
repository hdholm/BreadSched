# BreadSched 0.2.0a187

Application version: `0.2.0a187`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha adds income over time to Expense Explorer.

## Highlights

- Expense Explorer shows **Income over time** after Spending over time: planned
  and actual income for each period of the applied Plan, split by top-level income
  category, with the same to-date, future, and missing-quote markers, in the
  desktop application, the browser, and the printed report.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a186 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, and `SHA256SUMS` for the
tested commit.
