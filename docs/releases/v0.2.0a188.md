# BreadSched 0.2.0a188

Application version: `0.2.0a188`

Native schema version: `9`

Supported native schemas: `6–9`

This alpha adds net worth history.

## Highlights

- **Net worth history** shows assets, debts, and net worth valued at the end of
  each month, quarter, or year through today, with the change between periods and
  each top-level account's value. A point whose quote was missing on its date
  names the account instead of guessing. It is on the Dashboard in the desktop
  application and the browser, in the `net-worth` command, and in print.

## Native-book compatibility

No data-format change was made. Schema 9 books open directly; schemas 6, 7, and 8
still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
9 books; 0.2.0a143 through 0.2.0a187 can reopen them.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, and `SHA256SUMS` for the
tested commit.
