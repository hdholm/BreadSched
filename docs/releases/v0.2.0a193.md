# BreadSched 0.2.0a193

Application version: `0.2.0a193`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha adds savings goal editors to the desktop and browser.

## Highlights

- The desktop **Savings Goals…** window and the browser **Goals** page add, edit,
  fund, close, reopen, and delete savings goals, showing each goal's account,
  target date, target, amount set aside, what remains, and status.
- The Dashboard lists each open goal in a **Savings goals** table on the desktop,
  in the browser, and in the printout.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8, and
9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
10 books; 0.2.0a192 can reopen them. Alphas before 0.2.0a192 cannot open a schema 10
book; restore its pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, and `SHA256SUMS` for the
tested commit.
