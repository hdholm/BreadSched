# BreadSched 0.2.0a194

Application version: `0.2.0a194`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha brings savings goals into Plan, Projection, and scenarios.

## Highlights

- Goals are pinned across scenarios. A scenario can change a goal's target amount
  or target date, or leave it out, from the desktop Savings Goals window, the
  browser Goals page, or `breadsched goals --override`.
- Projection sets aside a share of the scenario's own projected income for each
  goal until its target month. It marks each goal's target month as a milestone
  that says whether projected cash covers the money set aside for goals then, and
  names the first month it does not. The projection CSV export adds each month's
  goal money and the cash left after it.
- Plan lists goals reaching their target date in its range, with what they have
  set aside so far.

## Native-book compatibility

No data-format change was made; scenario goal changes are stored in the existing
scenario record. Schema 10 books open directly; schemas 6, 7, 8, and 9 still
migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
10 books; 0.2.0a193 can reopen them and ignores scenario goal changes. Alphas
before 0.2.0a193 cannot open a schema 10 book; restore its pre-migration backup to
go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, and `SHA256SUMS` for the
tested commit.
