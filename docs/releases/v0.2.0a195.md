# BreadSched 0.2.0a195

Application version: `0.2.0a195`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha adds transaction tags and linked documents.

## Highlights

- Tag transactions from the desktop transaction editor, a browser register row
  (**Tags & documents…**), or `breadsched tags`. The desktop register filter
  matches tags, and `breadsched register --tag` lists one tag's transactions.
- Link receipts, statements, and web pages to a transaction. As in GnuCash, files
  stay outside the book: attaching copies a file into an attachment folder beside
  the book, or links it where it is. A missing file is marked and can be relinked;
  removing a document never deletes the file. `breadsched attachments --missing`
  lists every document that cannot be found.
- A GnuCash *Linked Document* is imported as a link and refreshed on re-import,
  while BreadSched's own tags and documents are kept.
- The transaction CSV export adds tags and documents columns.

## Native-book compatibility

No data-format change was made; tags and documents are stored in the existing
transaction record. Schema 10 books open directly; schemas 6, 7, 8, and 9 still
migrate automatically with a verified backup. A book backup does not include the
attachment folder; back that folder up with your other files.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema
10 books; 0.2.0a193 and 0.2.0a194 can reopen them and keep tags, but ignore linked
documents: saving a transaction there drops its documents, and a GnuCash
re-import there drops its tags and documents. Alphas before
0.2.0a193 cannot open a schema 10 book; restore its pre-migration backup to go
back.

## Verified artifacts
