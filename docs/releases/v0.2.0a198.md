# BreadSched 0.2.0a198

Application version: `0.2.0a198`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha widens GnuCash write-back to XML books and to most kinds of edit.

## Highlights

- Write-back works on XML books, GnuCash's default format, as well as SQLite. An
  XML book is changed only where a chosen transaction changes.
- It writes new transactions with any number of splits, changed amounts, accounts,
  and splits of imported transactions, and transactions you deleted in
  BreadSched. A transaction GnuCash has reconciled still only takes reconcile
  marks.
- Every kind of write is tested on books GnuCash 5.5 created and, in CI, opened
  in GnuCash itself afterwards.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup. Import an XML GnuCash
book once with this version before writing back to it, so that BreadSched records
which book and version it read.

## Upgrade and rollback

Keep an independent backup of a real book, and of your GnuCash book: write-back
keeps its own backups next to your BreadSched book. This version does not migrate
schema 10 books, and 0.2.0a197 reopens them unchanged. Alphas before 0.2.0a193
cannot open a schema 10 book; restore its pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, and `SHA256SUMS` for the
tested commit.
