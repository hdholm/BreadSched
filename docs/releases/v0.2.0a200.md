# BreadSched 0.2.0a200

Application version: `0.2.0a200`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha prints Dashboard, Plan, and Projection through the system print dialog.

## Highlights

- **Print** opens the system print dialog: print, preview where offered, or save a
  PDF. Tables continue across pages with their headings, and each page is numbered.
- The Plan's category detail is an option on the dialog's **Report** tab.
- **File → Print in Browser…** keeps the browser route, which prints the same
  report layout.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a199 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, and `SHA256SUMS` for the
tested commit.
