# BreadSched 0.2.0a202

Application version: `0.2.0a202`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha keeps the desktop within a small screen however long a book's names
and notes are.

## Highlights

- Every view fits in 1024 × 700; a long account name in a choice list is
  shortened in the middle, and the list still shows it in full.
- View toolbars scroll sideways, the Dashboard's cards wrap, and the window
  shrinks again after a large view.
- Dialogs open within the screen and scroll inside.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a201 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, and `SHA256SUMS` for the
tested commit.
