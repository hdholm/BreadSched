# BreadSched 0.2.0a207

Application version: `0.2.0a207`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha makes every read of a book see one saved state (#234).

## Highlights

- A browser page, report, or desktop projection that runs while another window
  saves no longer mixes data from before and after that save; the next read sees it.
- The book remains a single file, and a long read never delays saving.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup. Each read keeps a copy of
the book in memory while it runs.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a206 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, and `SHA256SUMS` for the
tested commit.
