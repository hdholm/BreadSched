# BreadSched 0.2.0a209

Application version: `0.2.0a209`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha shows whether each reported value covers every amount it should (#236).

## Highlights

- A Plan, Expense Explorer, or Projection figure that leaves out a foreign amount
  with no exchange rate is labelled **Partial** beside the number, in the period or
  cell it affects, and on the Projection chart.
- A Dashboard, net worth, or account total that cannot be valued completely is
  withheld and says which balances it leaves out.
- Each label opens a list of the excluded amounts, their currency and date, and the
  exchange rate or security price to add. Printed reports, `--json` output, and the
  Projection CSV carry the same status.
- A difference between two scenarios is only marked complete when both are.
- The User Guide describes each report's policy in one place, with an example.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a208 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

The Projection CSV export gains a final `completeness` column, and the web and
`--json` Dashboard, Plan, Projection, and net worth results gain `completeness`
objects. Existing fields are unchanged.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, and `SHA256SUMS` for the
tested commit.
