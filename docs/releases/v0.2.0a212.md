# BreadSched 0.2.0a212

Application version: `0.2.0a212`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha makes Review explain what it suggests and what each decision does.

## Highlights

- Each planned item Review offers for an actual transaction is marked **Close
  match** or **Possible match**, with its reasons: the accounts it shares, how far
  the amount and date are from the plan, and words the descriptions share.
- When Review offers nothing, it says why: the nearest planned item is outside the
  seven-day window, is planned in another currency, or was rejected, or no schedule
  uses the transaction's accounts.
- **Match**, **Reject**, **Skip**, **Unexpected**, and **Attach to FSA claim** each
  explain what they will do, in the desktop application and the browser.
- A transaction that moves FSA money names its FSA flow and how to attach it to a
  claim.
- `breadsched review` lists the transactions waiting for a decision with the same
  suggestions and reasons.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a211 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

The web `/api/review` response gains `confidence`, `label`, and `reasons` on each
candidate, `no_candidate_reason` and `fsa_hint` on the selected transaction, and
`action_help`. Existing fields are unchanged.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
