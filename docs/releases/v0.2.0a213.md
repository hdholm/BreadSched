# BreadSched 0.2.0a213

Application version: `0.2.0a213`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha proposes FSA statement lines for the claims they belong to.

## Highlights

- After you import or reconcile an FSA administrator's statement, the FSA Dashboard
  lists **Proposed claim links**: each payment from the FSA card, reimbursement, or
  provider refund that exactly one claim fits with a matching amount, with the claim,
  the role, and why. **Link selected** links the checked ones.
- Import and reconciliation say when proposals are waiting, in the desktop
  application and the browser.
- `breadsched claims --proposals` lists the proposals and `--link-proposals` links
  them.
- Correction: a provider refund to the FSA card that arrived after a claim was fully
  reimbursed was never suggested for that claim. It now is, in Review too.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a212 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

The web FSA Dashboard response gains `proposals`, import and reconciliation responses
gain `claim_link_notice`, and `POST /api/fsa/claim-links/accept` is new. Existing
fields are unchanged.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
