# BreadSched 0.2.0a214

Application version: `0.2.0a214`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha adds payroll templates and dated pay changes.

## Highlights

- **Payroll** (a Scheduled toolbar icon in the desktop application, a view in the
  browser, and `breadsched payroll`) reads each schedule shaped like a paycheck and
  shows its gross pay, taxes, deductions, savings, repayments, and net deposit as of
  a date, with the take-home share.
- A **pay change** sets a new gross from a date: taxes scale with gross by default,
  any line can be scaled, set to a new amount, or kept, and the net deposit takes the
  difference. Preview it first; saving keeps earlier paychecks unchanged.
- **Payroll templates** describe an employer's paycheck with each line a fixed
  amount or a percentage of gross, can be filled from an existing paycheck, and
  create new paycheck schedules.

## Native-book compatibility

No data-format change was made. Templates are kept in the existing book settings
table. Schema 10 books open directly; schemas 6, 7, 8, and 9 still migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a213 reopens them unchanged; it ignores saved payroll templates, and
pay changes remain ordinary per-line future amounts it already understands. Alphas
before 0.2.0a193 cannot open a schema 10 book; restore its pre-migration backup to go
back.

The web API gains `GET /api/payroll` and `POST /api/payroll/template/save`,
`/api/payroll/template/delete`, `/api/payroll/template/from-schedule`,
`/api/payroll/create`, `/api/payroll/change/preview`, and `/api/payroll/change`.
Existing fields are unchanged.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
