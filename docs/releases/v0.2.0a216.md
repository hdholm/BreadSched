# BreadSched 0.2.0a216

Application version: `0.2.0a216`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha reorganizes the browser interface's server code; what you see and do is
unchanged.

## Highlights

- Every browser request is now handled by a small adapter module for its area
  (schedules, scenarios, Review, imports, accounts, projection, and so on) that
  parses the request and calls the same shared services the desktop application and
  command line use. Schedule controls such as frequency, end date, skipped dates, and
  one-time amounts are parsed in one place for every schedule editor.
- A one-time schedule may now be saved from the browser with an end date or count
  still filled in; they are ignored, as the scenario editor already did.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a215 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

Web routes, requests, and responses are unchanged. Code importing
`breadsched.web.server.Api` still works; its handler methods are now functions in
the `breadsched.web.*_resource` modules.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
