# BreadSched 0.2.0a219

Application version: `0.2.0a219`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha imports CSV statements whose rows are split across several categories.

## Highlights

- **Split columns in CSV import.** When a statement lists a charge's categories in
  separate columns, such as a store receipt split between groceries and household
  goods, map a category column and an amount column for each split: **Add split
  columns** in the desktop and browser CSV import, or `--split CATEGORY=AMOUNT` on
  the command line. Each row's splits must add up exactly to its amount, or the
  preview marks the row invalid and says why; BreadSched never adds a balancing
  split or creates an account. The preview shows every row's splits before you
  import.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a218 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
