# BreadSched 0.2.0a220

Application version: `0.2.0a220`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha adds **Help** buttons that open the user guide where you need it.

## Highlights

- Windows and pages for longer workflows (imports, reconciliation, schedules and due
  review, paychecks, the Plan and Projection, Expense Explorer, net worth history,
  payees, rules, reimbursables, and goals) have a **Help** button. On the desktop it
  opens the guide window at that workflow's section; in the browser it opens the
  section in a new tab, so a form you are filling in is kept.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a219 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
