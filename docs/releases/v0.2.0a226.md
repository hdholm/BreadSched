# BreadSched 0.2.0a226

Application version: `0.2.0a226`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha stops OFX statements from duplicating transactions you already have.

## Highlights

- Importing an OFX/QFX bank or card statement now holds back a row that repeats a
  transaction already in the account, such as one you typed in or imported from a
  CSV, or the same activity downloaded again under a new bank identifier. The import
  summary says how many were held back. Choose **Include possible duplicates**
  (`--include-duplicates` on the command line) to import them anyway. Re-importing
  the same statement still changes nothing.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a225 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
