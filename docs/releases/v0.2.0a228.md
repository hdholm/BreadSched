# BreadSched 0.2.0a228

Application version: `0.2.0a228`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha reorganizes the Plan detail and book-verification code; nothing you see
changes.

## Highlights

- The code that explains a Plan cell (what you see when you open a Plan cell's
  detail in the desktop or browser, and in the Expense Explorer) now lives in its own
  module beside the Plan grid it explains. The explanations and values are
  unchanged; this keeps the Plan engine easier to maintain and review.
- The checks that stop an edit from leaving a book inconsistent moved out of the
  storage code into their own module. Every edit is still checked the same way.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a227 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
