# BreadSched 0.2.0a229

Application version: `0.2.0a229`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha shows what reimbursable expenses really cost you in the Plan.

**This version was never published.** The next version merged while its release
was being built, and a release is only published from the newest commit, so there
is no tag, release, or download for 0.2.0a229. Its changes are included in
0.2.0a230 and every later release.

## Highlights

- The Plan's Actual figures for a category are what you bear after reimbursements.
  The Plan now also lists each category with a reimbursable expense in the range,
  with its gross cost, what was reimbursed or is still expected back, and the net
  household cost, so you can see both without counting a reimbursement twice. A
  Plan cell's detail shows the same split for that period, the printed Plan
  includes the list, and `breadsched receivables BOOK --costs START END` prints it.
- The categorization rules dialog fits smaller screens with larger fonts again.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a228 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
