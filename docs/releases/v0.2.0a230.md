# BreadSched 0.2.0a230

Application version: `0.2.0a230`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha makes import summaries easier to act on.

## Highlights

- An import's summary now gives one line per reason records were skipped, most
  frequent first, with the first few records each reason stopped, instead of
  repeating every skipped record as its own warning. The warnings listed after it
  are only the ones that are not about a single record, such as a guessed number
  format. The command line's `--json` output adds `problems` and `notices`.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a229 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
