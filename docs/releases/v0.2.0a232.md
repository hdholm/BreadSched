# BreadSched 0.2.0a232

Application version: `0.2.0a232`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha lets a categorization rule fill in the payee as well.

## Highlights

- A rule that matches a description can also set a payee. Accepting its proposals
  then records both the category and the payee, so an imported "CORNER GROCER
  #1234" becomes a Groceries purchase from Corner Grocer in one step. A payee you
  already chose is never replaced. Choose **Also set payee** when adding a rule on
  the desktop or in the browser, or `--set-payee` on the command line.
- Deleting a payee now also removes the rules that match it, and rules that would
  set it keep their category without a payee.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a231 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
