# BreadSched 0.2.0a233

Application version: `0.2.0a233`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha requires Python 3.11 or later, adds tests, and fixes one problem they
found.

## Highlights

- New generated tests check money arithmetic and rounding across many amounts, and
  feed damaged and unusual QIF, OFX, and CSV statements to the importers to confirm
  that a bad file is either imported as far as it can be read or refused without
  changing the book.
- A CSV file or QIF price line that Python's CSV reader cannot read (for example,
  one with a NUL byte on Python 3.10) stopped the import with an unexplained error.
  Such a CSV file is now refused as not being CSV text, and such a price line is
  skipped and listed with the import's skipped records.
- **Python 3.11 or later is required.** Python 3.10 is no longer supported. The
  Windows installer and the Flatpak include their own Python and are unaffected.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a232 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
