# BreadSched 0.2.0a234

Application version: `0.2.0a234`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha fixes the dates of transactions imported from older GnuCash books in
time zones ahead of UTC.

## Highlights

- A GnuCash book saved as SQLite by a GnuCash version before 2.6.10 in Europe, Asia,
  Australia, or New Zealand imported every transaction and scheduled transaction a
  day early. BreadSched now reads those dates as the day you entered them. Import
  such a book again to correct transactions already imported. Newer GnuCash books,
  GnuCash XML books, and books from the Americas were not affected.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a233 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
