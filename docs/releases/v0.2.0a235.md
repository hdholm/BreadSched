# BreadSched 0.2.0a235

Application version: `0.2.0a235`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha lets a projection scenario draw down retirement savings.

## Highlights

- A scenario can withdraw monthly from a retirement or investment account into a
  cash account from a start date, either a fixed yearly amount that keeps pace with
  inflation or a yearly share of the account's balance, such as 4%. The projection
  shows the withdrawals, warns when the money runs out, and never takes more than
  the account holds. Use `breadsched drawdown` to set them up; desktop and browser
  editors follow.

## Native-book compatibility

No data-format change was made. Drawdowns are stored inside the scenario; an older
version ignores them and drops them if it saves that scenario. Schema 10 books open
directly; schemas 6, 7, 8, and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a234 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
