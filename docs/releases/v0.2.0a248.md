# BreadSched 0.2.0a248

Application version: `0.2.0a248`

Native schema version: `10`

Supported native schemas: `6–10`

This alpha reorganizes the shared wording code and the design documentation.
Nothing you see changes.

## Highlights

- The wording every interface shares (error messages, notices, and report
  sentences) is now grouped by area, and the design documentation is split into a
  document per topic. This prepares for the register and payee changes planned
  next. Every screen, command, and message reads exactly as before, including the
  Spanish translations.

## Native-book compatibility

No data-format change was made. Schema 10 books open directly; schemas 6, 7, 8,
and 9 still migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version does not migrate schema 10
books, and 0.2.0a247 reopens them unchanged. Alphas before 0.2.0a193 cannot open a
schema 10 book; restore its pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
