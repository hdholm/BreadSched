# BreadSched 0.2.0a250

Application version: `0.2.0a250`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha removes payees. A transaction's description is now its only name, as in
GnuCash.

## Highlights

- The Payee column, the payee pickers, the Payees screens, and the `payees` command
  are gone from the desktop, the browser, and the command line. Registers have one
  column fewer.
- Categorization rules match descriptions only. A rule you made to match a payee is
  converted, when the book is first opened, into rules for that payee's example
  descriptions, so it keeps categorizing the same transactions.
- Typing a description still proposes the rest of the entry from the latest
  matching transaction.
- A CSV statement's payee column can no longer be mapped; map it as the description
  instead.

## Native-book compatibility

Native schema advances from 10 to 11: the `payee` table is removed, and transactions
and rules no longer refer to payees. Schema 11 books open directly; schemas 6, 7, 8,
9, and 10 migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. This version migrates schema 6 through
10 books to schema 11 on first open; earlier alphas cannot reopen a schema 11 book
afterward. Restore the pre-migration backup to go back.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
