# BreadSched 0.2.0a252

Application version: `0.2.0a252`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha imports GnuCash stock splits and tidies the desktop File menu.

## Highlights

- **Stock splits from GnuCash.** GnuCash records a stock split as a single split
  that adds (or removes) shares with no value. Import used to skip it, so the
  shares were missing. It now arrives with a zero-value balancing line in
  **Equity:Share splits**, created when first needed, and Holdings and Cost Basis
  shows every lot holding proportionally more shares at the same cost. That line is
  BreadSched's own: re-importing keeps it, and GnuCash write-back never sends it.
  The command line's import summary counts `share_splits`.
- **Print in Browser** is no longer on the desktop File menu on Linux or Windows,
  which print natively through **File → Print Current View…**. It remains on macOS
  until BreadSched prints natively there. The browser interface's own printing is
  unchanged.

## Native-book compatibility

No schema change. A split stores a new `importer_added` flag only when it is set,
so existing transactions are stored exactly as before. Schema 11 books open
directly; schemas 6 through 10 migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Re-import the GnuCash book once to pick
up its stock splits. Going back to 0.2.0a251 reads imported share splits as ordinary
two-split transactions; earlier alphas cannot reopen a schema 11 book.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
