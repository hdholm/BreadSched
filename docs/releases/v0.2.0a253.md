# BreadSched 0.2.0a253

Application version: `0.2.0a253`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha makes the desktop register work like GnuCash's.

## Highlights

- **Click to edit.** Click any transaction (or select it and press F2) to edit it
  where it is.
- **Up and Down move while you type.** They save the transaction you are leaving if
  you changed it, then edit the one above or below; in a split transaction they
  first move between its split lines. Below the last transaction is the blank row.
  If the transaction cannot be saved, you stay on it and the reason is shown.
- **Matching accounts are listed** under the register while you type an account
  path such as `Ex:Gr`; the first is chosen, and clicking another chooses it.
- **R column.** Each row shows **n**, **c**, or **y**. Click **n** or **c** to mark
  an entry cleared or not cleared; an open statement for the account picks up the
  change. Reconciled entries change only by reopening their statement.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a252 needs no
restore; earlier alphas cannot reopen a schema 11 book.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
