# BreadSched 0.2.0a254

Application version: `0.2.0a254`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha brings the desktop register's editing to the browser.

## Highlights

- **Click a row to edit it** in the browser register (**Edit** still works).
- **Up and Down** in a field save the row you are leaving if you changed it, then
  edit the row above or below; below the last transaction is the blank row. A row
  that cannot be saved keeps you there and says why.
- **Matching accounts are listed** under an account choice while you type a path
  such as `Ex:Gr`; click one to choose it.
- **R column.** Each row shows **n**, **c**, or **y**; click **n** or **c** to mark
  an entry cleared or not cleared. An open statement for the account picks up the
  change, and reconciled entries change only by reopening their statement.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a253 needs no
restore; earlier alphas cannot reopen a schema 11 book.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes
a source distribution, pure-Python wheel, Windows installer, Flatpak bundle, and
`SHA256SUMS` for the tested commit.
