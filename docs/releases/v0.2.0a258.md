# BreadSched 0.2.0a258

Application version: `0.2.0a258`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha adds native Linux packages for Debian, Ubuntu, and Fedora. It was not
published: its release run failed while installing the `.deb`, and its changes
first ship in [0.2.0a259](v0.2.0a259.md).

## Highlights

- **`.deb` and `.rpm` packages.** Each release now attaches
  `breadsched_<version>_all.deb` (Ubuntu 24.04 or later, Debian 12 or later) and
  `breadsched-<version>-1.noarch.rpm` (Fedora). They use your system's Python 3 and
  GTK 4 and install with `sudo apt install ./…deb` or `sudo dnf install ./…rpm`,
  which fetches what they need.
- **Finance::Quote works with them.** The packages recommend Finance::Quote, so
  its quote sources work for online quotes, as they cannot from the Flatpak.
- Removing a package never removes a book.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. The Flatpak and a native package are
separate installations; use one. Going back to 0.2.0a257 needs no restore; earlier
alphas cannot reopen a schema 11 book.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
