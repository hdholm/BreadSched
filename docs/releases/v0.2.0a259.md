# BreadSched 0.2.0a259

Application version: `0.2.0a259`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha adds tests of online quotes against the real quote sources, and it is
the first published release with the Debian/Ubuntu and Fedora packages: 0.2.0a258,
which introduced them, was not published because its release run failed. See
[0.2.0a258](v0.2.0a258.md) for what the packages are and how to install them.

## Highlights

- **Live quote tests.** Opt-in tests fetch from tsp.gov, the ECB, Alpha Vantage,
  and Finance::Quote, and store the results through the service, command line,
  browser route, desktop dialog, and an installed `breadsched`. Run them where
  internet access is open with `BREADSCHED_NETWORK_TESTS=1 pytest -m network -rs`;
  set `ALPHAVANTAGE_API_KEY` to test your key, and `BREADSCHED_FQ_METHOD` and
  `BREADSCHED_FQ_SYMBOL` to check a Finance::Quote source you rely on.
- A weekly workflow runs them, so a provider's format change is noticed promptly.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a257 needs no
restore (0.2.0a258 was not published); earlier alphas cannot reopen a schema 11
book.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
