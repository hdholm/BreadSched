# BreadSched 0.2.0a260

Application version: `0.2.0a260`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha fixes dialogs that could open behind the desktop window at start-up
(#295) and shows progress while an old book is upgraded.

## Highlights

- **No more hidden dialogs.** The upgrade notice, other alerts, and the due and
  GnuCash change reviews wait until the main window is on screen, so they always
  open in front of it. Before, starting with a book that needed upgrading could
  leave the notice behind the main window, which then ignored input while it
  waited.
- **Upgrading says so.** Opening a book from an earlier alpha now shows the window
  at once with "Upgrading *book* from an earlier BreadSched format", naming its
  schema, while the verified backup is written and the book is migrated. If the
  upgrade fails, the start screen returns with the reason.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a259 needs no
restore; earlier alphas cannot reopen a schema 11 book.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
