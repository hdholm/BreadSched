# BreadSched 0.2.0a261

Application version: `0.2.0a261`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha changes how the test suite and build workflows run; the application is
unchanged.

## Highlights

- **GTK tests no longer use your desktop.** Running `pytest` or `pytest -n auto`
  from a source checkout now puts every test window on a private virtual display
  when `Xvfb` is installed (`xvfb` on Debian and Ubuntu, `xorg-x11-server-Xvfb` on
  Fedora). Windows no longer flash or take focus, and a parallel run can no longer
  crash GTK on a GNOME/Wayland desktop. Set `GUI_VISIBLE=1` to watch the tests.
- **Build workflows on Node 24.** CI and releases move artifacts with
  `upload-artifact@v7` and `download-artifact@v8`, replacing versions that ran on
  GitHub's deprecated Node 20.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a260 needs no
restore; earlier alphas cannot reopen a schema 11 book.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
