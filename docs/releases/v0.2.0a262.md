# BreadSched 0.2.0a262

Application version: `0.2.0a262`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha reports which Finance::Quote you have and records what the first live
quote runs found.

## Highlights

- **Quotes checked against the real sources.** The live tests fetched every TSP
  fund from tsp.gov, ECB exchange rates, and an Alpha Vantage quote, and stored
  them through the command line, the browser route, and an installed
  `breadsched`.
- **Use a current Finance::Quote.** Its current release (1.71) fetched US stock
  quotes; version 1.59, which Ubuntu 24.04 packages, was refused by every source
  that needs no key. If quotes from a Finance::Quote source fail, install the
  current release with `sudo cpanm Finance::Quote` (from the `cpanminus` package)
  or use `alphavantage`. Online quotes now shows the installed version, for
  example *Finance::Quote 1.59 is installed*.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a261 needs no
restore; earlier alphas cannot reopen a schema 11 book.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
