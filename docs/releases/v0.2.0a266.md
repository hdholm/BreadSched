# BreadSched 0.2.0a266

Application version: `0.2.0a266`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha adds Budget jars and a single explanation of how BreadSched plans.

## Highlights

- **Every plan is a jar.** Each scheduled payment, each estimate such as groceries,
  and each savings goal is a jar. Your scheduled income fills it, each paycheck by
  its share of the income before the due date, as the Dashboard already reserves
  bills. The actual transaction matched to it in Review draws it down, so spending
  less leaves money in the jar and spending more shows as a variance.
- **Budget jars report.** For the Plan's range, see each account's jars by month,
  quarter, or year: what was filled, what was planned and actually spent, the
  difference, and what is left. Open an account to see each jar. Print it from the
  desktop or the browser, or run `breadsched jars`.
- **How it fits together.** The User Guide's new section *Jars: how the pieces fit
  together* follows one paycheck and one grocery estimate through every view.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup. Jars are calculated from the book and never
stored.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a265 needs no
restore; that version has no Budget jars report.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
