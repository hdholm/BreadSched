# BreadSched 0.2.0a267

Application version: `0.2.0a267`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha adds charts to Budget jars and the shared charting every view will use.

## Highlights

- **Budget jars charts.** Each account in Budget jars shows two charts: planned
  against actual spending for every period, and each jar's level beside its target
  (the next planned payment, or a goal's target). Hover over a column for its exact
  amount; a table of the exact values sits beside every chart, on screen and in
  print.
- **One look for charts.** Desktop, browser, and printed charts share one set of
  colours, chosen to stay distinguishable for colour-blind readers and stepped for
  dark desktop themes.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a266 needs no
restore; that version shows Budget jars without charts.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
