# BreadSched 0.2.0a269

Application version: `0.2.0a269`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha makes Budget jar levels account for everything that came before.

## Highlights

- **Levels carry in earlier months.** A jar's level now includes every fill and
  every matched spend since its schedule began. Money an earlier month left over,
  or overspent, is carried into the months you report, so any range ends at the
  same level.
- **Unmatched months stay in the jar.** An occurrence never matched to an actual
  transaction keeps its money set aside until you match it or skip it in Review,
  so the jar shows what is still spoken for.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup. Jars are calculated from the book and never
stored.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a268 needs no
restore; that version starts each report's levels from the range's own
occurrences.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
