# BreadSched 0.2.0a272

Application version: `0.2.0a272`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha shows where the Projection's money sits at each year end.

## Highlights

- **Year-end balances by account.** A new Projection chart shows each projection
  year's last month as one column: cash and each investment account above zero,
  each debt below, adding up to that year's net worth. The seven largest balances
  are named and the rest are combined as Other.
- **Everywhere the Projection is.** The desktop view, the browser page (with the
  exact values under Chart values), and the printout show it; its values print
  in the optional Projection chart values section.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup. Charts are drawn from the projection and
never stored.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a271 needs no
restore; that version shows only the totals chart.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
