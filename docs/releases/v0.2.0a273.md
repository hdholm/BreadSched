# BreadSched 0.2.0a273

Application version: `0.2.0a273`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha charts savings goals and investment holdings, completing BreadSched's
move to one shared chart design.

## Highlights

- **Goal progress at a glance.** The Savings Goals list now has a chart: one
  column per open goal, labelled with its target month, showing what is set aside
  under what is still to save, so each column reaches the goal's target.
- **Holdings: cost against market value.** Holdings and Cost Basis charts each
  holding's cost, market value, and unrealized gain side by side, one chart per
  currency the holdings cost in.
- **Every chart, one design.** Budget jars, the Projection, the Expense Explorer,
  Net worth history, goals, and holdings now share the same colours, hover
  amounts, and a table of exact values beside each chart.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup. Charts are drawn from the book and never
stored.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a272 needs no
restore; that version shows these lists without charts.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
