# BreadSched 0.2.0a274

Application version: `0.2.0a274`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha makes the desktop register feel like a checkbook register, closer to
GnuCash.

## Highlights

- **Opens where you work.** A register opens on the blank entry row at the bottom,
  showing the newest transactions, ready for typing.
- **Quiet rows, one editor.** Rows are plain ruled lines; only the cell being edited
  shows an input, on a highlighted row.
- **Type-ahead accounts.** Typing a transfer account completes it as you go: the
  rest of the best match is selected so the next letter narrows it, `:` moves to
  the subaccounts, and the matching accounts are listed under the cell. New
  descriptions complete from earlier ones too.
- **Split transactions stay put.** Clicking a split transaction opens its split
  lines in place; it no longer jumps back to the first row.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a273 needs no
restore; that version shows the earlier register.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
