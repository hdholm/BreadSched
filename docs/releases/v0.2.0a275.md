# BreadSched 0.2.0a275

Application version: `0.2.0a275`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha fixes Budget jars so that real spending shows up as actuals (#312).

## Highlights

- **Every purchase counts.** A transaction posted to a jar's account is an actual
  draw even if you never matched it to a planned occurrence in Review, so a
  groceries jar's actuals now agree with the Plan's Groceries row. Refunds put
  money back in the jar.
- **Unmatched spending line.** When an account has several jars and spending could
  belong to any of them, it appears as **Unmatched spending** in that account, so
  the account's totals still agree with the Plan.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup. Jars are computed from the book and never
stored.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a274 needs no
restore; that version counts only matched transactions in jars.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
