# BreadSched 0.2.0a276

Application version: `0.2.0a276`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha fixes Help buttons in desktop dialogs (#314).

## Highlights

- **Help no longer freezes.** Choosing **Help** in the import dialog (or any other
  dialog that keeps the main window waiting) opened a guide that ignored every
  click until the dialog closed. The guide now works while the dialog stays open,
  and it opens above the dialog.
- **Help opens at the right place.** The guide now scrolls to the section for the
  dialog you came from instead of showing the start of the desktop guide.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a275 needs no
restore; that version has the frozen Help window.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
