# BreadSched 0.2.0a280

Application version: `0.2.0a280`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha makes switching between views in the desktop window quick.

## Highlights

- **Instant switching.** Going back to Plan, the Dashboard, or a register used to
  recalculate it every time, which took seconds on a long book. A view is now
  redrawn only when something in the book changed since you last saw it, or the
  day has turned; otherwise it appears as you left it.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a279 needs no
restore.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
