# BreadSched 0.2.0a282

Application version: `0.2.0a282`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha fixes posting scheduled transactions from the menu, several desktop
register annoyances, and drop-down choices shown a few letters wide.

## Highlights

- **Post Scheduled Transactions reviews what is due (#326).** The menu item opened
  the Scheduled view; it now opens the same review as opening a book, or says that
  nothing is due.
- **The register moves on after an edit (#325).** Enter, or Tab past the last cell,
  on a transaction you changed now saves it and moves to the next transaction, also
  in Double Line mode and on a split transaction.
- **Shading you can choose (#325).** Rows shade by transaction by default, so Double
  Line keeps alternating; you can also shade alternate lines or turn shading off.
  The choice is remembered.
- **The keyboard stays in the register (#325).** Turning on Double Line, splitting,
  or changing the shading no longer leaves the keys with the toolbar button.
- **Find accounts by any part of their name (#325).** Typing `groc` under Transfer
  lists Expenses:Groceries; a `:` still matches level by level.
- **Drop-down choices show whole (#327).** Choices such as "Scale with gross" and
  "Remind me later" are no longer shortened, and their lists no longer wrap a word a
  few letters at a time.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a281 needs no
restore.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
