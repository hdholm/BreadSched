# BreadSched 0.2.0a283

Application version: `0.2.0a283`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha shows what a due review posted, so it can be checked and corrected
straight away (#328).

## Highlights

- **Posted transactions to review.** After **Apply** posts scheduled transactions
  in the desktop window, a **Posted transactions** window lists each one with every
  split on its own line (account, memo, and amount under the account's own heading),
  instead of only a count.
- **Edit or delete on the spot.** **Edit…** opens a transaction in the full editor
  and **Delete** removes it; both are ordinary changes that Ctrl+Z undoes, and the
  list shows what is stored after each.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a282 needs no
restore.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
