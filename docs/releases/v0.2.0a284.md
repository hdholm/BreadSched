# BreadSched 0.2.0a284

Application version: `0.2.0a284`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha makes the keyboard and dialogs behave the same way throughout the desktop
window.

## Highlights

- **The keyboard follows the tab you choose (#331).** Choosing a register tab puts
  the keyboard in its cell, as choosing a view icon or menu item does.
- **Tab shortcuts.** Ctrl+Page Up and Ctrl+Page Down move between tabs, Ctrl+W
  closes one, and Ctrl+F (Edit → Find in Register) goes to the register's filter.
- **Overwrite a proposed value (#332).** Arriving in a register cell selects all of
  it, so typing or Backspace replaces it; Left or Right goes to its start or end.
- **Dialogs behave alike (#335).** Escape closes any dialog, Enter chooses its main
  button, and every dialog has a Help button. New guide sections cover accounts,
  Dashboard groups, loans, and FSA claims.
- **Every delete asks first (#335).** Delete buttons are styled alike and ask
  "Delete …?" before removing anything, in the desktop window and the browser.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a283 needs no
restore.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
