# BreadSched 0.2.0a285

Application version: `0.2.0a285`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha makes every account choice in the desktop window searchable (#334).

## Highlights

- **Search any long choice list.** Opening a list of eight or more choices, such as
  the register's account picker or any account choice in a dialog, shows a search
  field; typing part of a name keeps only the choices that contain it.
- **The register's account list follows the keyboard.** Moving through the accounts
  listed under the Transfer cell with Up and Down scrolls the list so the chosen
  account stays in view.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a284 needs no
restore.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
