# BreadSched 0.2.0a286

Application version: `0.2.0a286`

Native schema version: `11`

Supported native schemas: `6–11`

This alpha adds a Preferences window (#333) and makes the desktop menus, toolbar
icons, and names consistent (#336).

## Highlights

- **Edit → Preferences… (Ctrl+,).** Choose or forget the book opened at start, set
  Double Line and row shading for every register, enter the Alpha Vantage API key,
  and open Configure Dashboard Groups, all in one window. The register toolbar no
  longer carries the Double Line and shading controls; **View → Double Line** turns
  the notes line on or off in every open register.
- **A Reports menu.** Net Worth History, Holdings and Cost Basis, Realized Gains,
  Tax Year, Explore Expenses, and Budget Jars are listed together, whichever view
  you are in.
- **One name for each command.** **Review Due Transactions…** replaces Post
  Scheduled Transactions and Review Due; New Transaction (Ctrl+T) is the one way to
  open the transaction editor for a new entry and starts in the register you are
  looking at. Menu items that ask for more end in "…".
- **One meaning for each toolbar icon.** Icons that stood for two different
  commands now differ, and every icon is one the current GNOME icon theme provides.
- **Matching names in the browser.** The navigation bar's **Reimbursables** and
  **Goals** are now **Reimbursable Expenses** and **Savings Goals**.

## Native-book compatibility

No schema change. Schema 11 books open directly; schemas 6 through 10 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a285 needs no
restore; Preferences writes only settings 0.2.0a285 already reads.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
