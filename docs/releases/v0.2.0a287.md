# BreadSched 0.2.0a287

Application version: `0.2.0a287`

Native schema version: `12`

Supported native schemas: `6–12`

This alpha stores each account's Dashboard group in one place (#337) and removes
duplicated internal types and functions (#338).

## Highlights

- **One place says which Dashboard group an account is in.** The group an account
  shows in its editor and the group the Dashboard groups window checks it in are now
  the same thing, so they can no longer disagree. Saving the groups window with an
  account checked in two groups explains why and changes nothing; the browser does
  the same.
- **Changing the Dashboard's horizons keeps your groups.** Changing the liquidity or
  emergency-fund horizon no longer rewrites groups changed since the Dashboard was
  drawn. Changes to groups and horizons can be undone like other changes to the book.
- **Internal simplification.** FSA claims and reimbursable expenses link to ledger
  splits through one shared record, and the ledger's duplicate balance functions are
  gone. Nothing you see changes.

## Native-book compatibility

Schema 12. Opening a schema 11 book migrates it automatically, after a verified
backup: each account that the Dashboard groups listed takes the first group it was
listed in, which is the group it was shown in, and the stored Dashboard settings
keep only group names and kinds. Two groups with the same name become one. Schemas
6 through 10 migrate the same way through each step.

## Upgrade and rollback

Keep an independent backup of a real book. 0.2.0a286 cannot open a schema 12 book;
to go back, restore the backup that opening the book in 0.2.0a287 wrote beside it
(its name ends in `.pre-migration-v11.bak`; a book opened through the document portal
keeps it in BreadSched's data folder).
