# BreadSched 0.2.0a290

Application version: `0.2.0a290`

Native schema version: `12`

Supported native schemas: `6–12`

This alpha adds Enter and Cancel buttons to the desktop register (#344).

## Highlights

- **Cancel an entry without knowing Escape.** The register toolbar has **Enter** and
  **Cancel**, as in GnuCash. **Cancel** puts the transaction you are typing in or
  changing back as it was (a new one empties); **Enter** saves it. **Actions → Enter
  Transaction** and **Cancel Transaction** do the same, and the Enter and Escape keys
  still work.

## Native-book compatibility

No schema change. Schema 12 books open directly; schemas 6 through 11 migrate
automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a289 needs no
restore.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
