# BreadSched 0.2.0a291

Application version: `0.2.0a291`

Native schema version: `12`

Supported native schemas: `6–12`

This alpha makes desktop windows open at the size you last gave them (#349).

## Highlights

- **The main window comes back as you left it.** Its size, and whether it was
  maximized, is remembered when you close it or quit, and used the next time you
  start, whichever book you open.
- **Resized windows stay resized.** An independent register window remembers its
  size, and any dialog you resize opens at that size next time; a dialog you have
  not resized still opens at the size its contents need. A remembered size never
  exceeds the screen.
- **A way back.** **Edit → Preferences… → Windows → Forget remembered window
  sizes** returns every window to its own size.

## Native-book compatibility

No schema change. Sizes are kept in your user settings, not in any book. Schema 12
books open directly; schemas 6 through 11 migrate automatically with a verified
backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a290 needs no
restore; it ignores the remembered sizes.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
