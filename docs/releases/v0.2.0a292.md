# BreadSched 0.2.0a292

Application version: `0.2.0a292`

Native schema version: `12`

Supported native schemas: `6–12`

This alpha lets a scheduled transaction be dealt with before its date, as GnuCash
does (#351, #352).

## Highlights

- **Enter Next and Skip Next.** In Scheduled, enter or skip a schedule's next
  occurrence now, however far ahead it is. It keeps its own date, the schedule moves
  on to the following one, and Undo reverses either. The browser and the command
  line (`breadsched scheduled-next`) do the same.
- **Enter in advance.** A schedule can join the due review a number of days before
  its date, marked *in advance*; one set to post automatically posts that far
  ahead. GnuCash's *create in advance* days, already imported, now take effect.
- **Remind in advance.** A schedule can also appear in the due review as a
  *reminder* that many days early. Reminders are never posted automatically, and
  `due-review --post-all` leaves them for you. GnuCash's *remind in advance* days
  are imported.
- Both counts are set in the desktop and browser schedule editors or with
  `breadsched scheduled-advance`, from 0 to 999 days.

## Native-book compatibility

No schema change. A schedule's reminder days are stored with it only when set, so
books open unchanged in either direction. Schema 12 books open directly; schemas 6
through 11 migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a291 needs no
restore; it ignores reminder days, and lists occurrences only once they are due.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
