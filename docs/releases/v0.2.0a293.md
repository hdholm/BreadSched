# BreadSched 0.2.0a293

Application version: `0.2.0a293`

Native schema version: `12`

Supported native schemas: `6–12`

This alpha tidies the desktop toolbar and makes register entry quicker to correct
(#361, #363, #364).

## Highlights

- **Move a transaction to another account from its split.** A purchase entered on
  the wrong credit card can be moved by changing its split's account in the
  register, in the desktop and browser registers alike. The register says the
  transaction moved and no longer shows there. A new entry still needs a split in
  the register's account.
- **Notes from the last matching transaction.** When the register or transaction
  editor fills an entry from the last one with the same description, it now fills
  that transaction's notes too, if the new entry has none yet.
- **Typed case is kept.** If you keep typing past a description or account
  completion that no longer matches, the field shows the letters as you typed them.
- **A tidier toolbar.** Open and Import are in the **File** menu and start screen
  only. The view icons come first, then the current view's name in bold, then that
  view's own commands. A register has a **Reconcile** icon, and the account and
  transaction counts appear only on the Dashboard and Accounts.

## Native-book compatibility

No schema change. Books open unchanged in either direction. Schema 12 books open
directly; schemas 6 through 11 migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a292 needs no
restore.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
