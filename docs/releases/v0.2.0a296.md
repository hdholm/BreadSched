# BreadSched 0.2.0a296

Application version: `0.2.0a296`

Native schema version: `12`

Supported native schemas: `6–12`

This alpha makes scheduled transactions more flexible (#370).

## Highlights

- **Every N weeks, months, or years.** A schedule can repeat every so many days,
  weeks, months, or years: every 4 weeks, every 2 months, every 3 years. It can also
  repeat on the same or last weekday of every N months, twice a month, or once. The
  first due date sets the day.
- **Imported rules are ordinary.** A schedule GnuCash imports as, say, every 4 weeks
  is no longer an "imported rule"; it is edited like any other, in the desktop and
  the browser.
- **Calculated amounts.** A schedule's amount can be a calculation such as
  `76.84*1.06`, as in the register.

## Native-book compatibility

No schema change. Books open unchanged in either direction. Schema 12 books open
directly; schemas 6 through 11 migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a295 needs no
restore; a schedule saved with a new interval keeps it, and the older editors show
it as an imported rule again.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
