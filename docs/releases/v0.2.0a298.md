# BreadSched 0.2.0a298

Application version: `0.2.0a298`

Native schema version: `12`

Supported native schemas: `6–12`

This alpha fixes tracking reimbursable expenses from the register and makes
reconciling quicker (#371, #374, #375).

## Highlights

- **Track as Reimbursable opens every time.** The desktop command saves what you
  were typing, then opens **Reimbursable expenses** over the register window. If
  the transaction cannot be tracked, an alert says why.
- **Receivable accounts explained.** **Held in** lists accounts of type Receivable,
  and a note names any account that looks like a receivable but is not offered, so
  you can change its type. GnuCash accounts under Assets:Receivables now import as
  Receivable accounts.
- **Click to check, double-click to edit.** In the desktop reconcile window one
  click checks a row and selects only it. Ctrl- or Shift-click selects several,
  and a double-click edits the transaction. In the browser, **Edit** on a
  statement row opens it in the register, and **Back to reconciliation** returns.

## Native-book compatibility

No schema change. Books open unchanged in either direction. Schema 12 books open
directly; schemas 6 through 11 migrate automatically with a verified backup.
Accounts already imported keep their type; change an Asset receivable to
Receivable with **Edit Account**.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a297 needs no
restore.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
