# BreadSched 0.2.0a300

Application version: `0.2.0a300`

Native schema version: `12`

Supported native schemas: `6–12`

This alpha makes finding transactions and choosing accounts easier (#382, #381).

## Highlights

- **Filter by amount.** The register filter now matches amounts and dates as well
  as text, so typing 67 finds a 67.00 charge. The browser register has the same
  filter.
- **Taller account lists.** Account choices in the desktop window open tall enough
  to scroll and search comfortably.

## Native-book compatibility

No schema change. Books open unchanged in either direction. Schema 12 books open
directly; schemas 6 through 11 migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a299 needs no
restore.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
