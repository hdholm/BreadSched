# BreadSched 0.2.0a301

Application version: `0.2.0a301`

Native schema version: `13`

Supported native schemas: `6–13`

This alpha gives each transaction and account one note, shared with GnuCash
(#385).

## Highlights

- **One note.** An imported transaction or account used to show two notes:
  GnuCash's, read-only and replaced on every import, and BreadSched's own. They are
  one editable note now. The first import fills it from GnuCash; a later import
  brings GnuCash's changes only while you have not edited the note, and when both
  changed it keeps yours and says how many it kept.
- **Notes are written back.** GnuCash write-back sends each transaction's note,
  even to a transaction GnuCash has reconciled, so the two books keep the same
  notes.

## Native-book compatibility

Schema 13. Opening a schema 12 book migrates it automatically, after a verified
backup: a transaction or account with both notes gets GnuCash's text first, then a
blank line and BreadSched's (the same text once). Schemas 6 through 11 migrate the
same way through each step.

The first write-back after upgrading lists every imported transaction whose
joined note now differs from GnuCash's, so GnuCash receives the joined text. Leave
those transactions unchosen to keep GnuCash's notes as they are.

## Upgrade and rollback

Keep an independent backup of a real book. 0.2.0a300 cannot open a schema 13 book;
to go back, restore the backup that opening the book in 0.2.0a301 wrote beside it
(its name ends in `.pre-migration-v12.bak`; a book opened through the document portal
keeps it in BreadSched's data folder).

## Verified artifacts
