# BreadSched 0.2.0a302

Application version: `0.2.0a302`

Native schema version: `13`

Supported native schemas: `6–13`

This alpha puts everything the Dashboard can be told in one place (#381).

## Highlights

- **Configure Dashboard.** One dialog, in the desktop window and the browser, holds
  the two horizons (moved off the Dashboard), which sections show, the account
  groups, and each table's columns.
- **Simpler groups.** A group lists only its own accounts, each with a remove
  button, and a searchable **Add an account…** list adds another. Adding an account
  to one group takes it out of another.
- **Pending reimbursables.** An optional table lists each reimbursable expense still
  owed, as Pending bills lists bills: payer, dates, what is still owed, and status.
- **Columns are yours.** Dashboard column choices stay per user (desktop settings or
  the browser), never in the book.

## Native-book compatibility

No schema change. The chosen sections are stored with the book's existing Dashboard
settings; a book without them shows every section but pending reimbursables, as
before. Schema 13 books open directly; schemas 6 through 12 migrate automatically
with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a301 needs no restore;
it ignores the stored sections.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
