# BreadSched 0.2.0a303

Application version: `0.2.0a303`

Native schema version: `13`

Supported native schemas: `6–13`

This alpha makes the transaction and schedule editors simpler to read (#383).

## Highlights

- **Schedule editors on pages.** The desktop's schedule and scenario editors open on
  **Basics**: name, kind, accounts, amount, and when it repeats.
  - **Splits**, **Future changes**, and **Advanced** are a tab away, and the Future
    changes tab counts what it holds.
  - In the browser, the same groups fold away and open when chosen.
- **Less in the transaction editor.**
  - Tags and documents move to a second tab.
  - Each split's planning purpose shows on request, and investment activity only for
    an investment or retirement account.
  - A value already chosen always stays visible.
- **Investment activity where it applies.** Schedules, scenario estimates, and the
  browser's two-split entry offer investment activity only for investment and
  retirement accounts.

## Native-book compatibility

No schema change. Books open unchanged in either direction. Schema 13 books open
directly; schemas 6 through 12 migrate automatically with a verified backup.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a302 needs no
restore.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
