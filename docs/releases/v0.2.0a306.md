# BreadSched 0.2.0a306

Application version: `0.2.0a306`

Native schema version: `13`

Supported native schemas: `6–13`

This alpha fixes a field report (#393): dates read alike in every desktop field, the
reconcile window no longer stays on top and shows check numbers, imported accounts
can be edited, and shown hidden accounts can be used.

## Highlights

- **Dates.** Every desktop date field accepts what the register accepts (`3/15/26`,
  `3/15`, `15`, `t`, `+`, `-`, `]`, `[`, and the rest) and shows the date as
  `YYYY-MM-DD` when you leave it.
- **Reconciling.** The main window can be brought in front of the reconcile window,
  and each entry shows its check number, by which either list sorts.
- **Imported accounts.** Rename, move, unhide, or otherwise change an account
  imported from GnuCash, its other GnuCash fields too; a later import keeps your
  changes and still brings what changed only in GnuCash.
- **Hidden accounts.** With **View → Show Hidden Accounts** on, hidden accounts take
  transactions and are offered everywhere an account is chosen.

## Native-book compatibility

No schema change. An edited imported account stores the values it was imported
with as one more field, which earlier versions ignore. Books open unchanged in
either direction.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a305 needs no
restore; an account changed here keeps its changes there, but a re-import there
refreshes its chart fields from GnuCash as before.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
