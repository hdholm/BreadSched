# BreadSched 0.2.0a307

Application version: `0.2.0a307`

Native schema version: `13`

Supported native schemas: `6–13`

This alpha fixes the desktop on newer GTK and Adwaita releases (#395), found by
running the tests on a newer desktop than CI's.

## Highlights

- **Unbalanced entries.** The row the transaction editor adds for the rest of an
  unbalanced entry shows **Choose an account…** until you choose one, on every GTK
  version; on GTK 4.16 and later it had kept the first account, so the entry could
  be saved out of balance.
- **Keyboard focus.** Ctrl+F keeps the keyboard in the register's filter, and a
  register no longer reaches for a book that has just closed.
- **Icons.** **Manage FSA Claims…** has an icon current Adwaita still ships.

## Native-book compatibility

No schema change. Books open unchanged in either direction.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a306 needs no
restore.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
