# BreadSched 0.2.0a309

Application version: `0.2.0a309`

Native schema version: `13`

Supported native schemas: `6–13`

This alpha lets a recorded transaction become a scheduled one from the register
(#392).

## Highlights

- **Make Scheduled.** In a desktop register, put the cursor on a transaction and
  choose **Actions → Make Scheduled…**: a new scheduled transaction opens with all
  of its splits. Choose how often it repeats, and whether it is a commitment or an
  estimate, then save. The browser register's **Make scheduled…** row action does
  the same.
- **No accidental repeat of what is recorded.** The new schedule starts a month
  after the transaction, monthly, rather than on the transaction's own date, where
  it would have come up due at once.

## Native-book compatibility

No schema change. Books open unchanged in either direction.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a308 needs no
restore.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
