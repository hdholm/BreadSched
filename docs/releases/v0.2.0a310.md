# BreadSched 0.2.0a310

Application version: `0.2.0a310`

Native schema version: `13`

Supported native schemas: `6–13`

This alpha fixes a field report (#397): hidden accounts are never refused, and
several desktop windows behave better.

## Highlights

- **Hidden accounts work.** With **View → Show Hidden Accounts** on, a hidden account
  takes new transactions, schedules, card payments, and loans like any other, and is
  marked **(hidden)**. The setting no longer switches to the Accounts view.
- **Report a problem from Help.** **Help → Report a Problem…** opens GitHub's bug
  report form with this version filled in; **Request a Feature…** its feature form.
- **Reconciling.** Editing a transaction from the reconcile window no longer locks the
  main window.
- **Dashboard.** Its tables wrap beside each other as the window widens or narrows,
  and a table switched off leaves no gap.
- **FSA Dashboard.** It loads in the background, showing **Updating…** rather than
  freezing.

## Native-book compatibility

No schema change. Books open unchanged in either direction.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a309 needs no
restore; a hidden account used here stays in those transactions there.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
