# BreadSched 0.2.0a311

Application version: `0.2.0a311`

Native schema version: `13`

Supported native schemas: `6–13`

This alpha fixes a field report (#401): GnuCash schedules no longer offer occurrences
GnuCash already entered, and the schedule editors' Upcoming list shows future
changes.

## Highlights

- **Imported schedules start where GnuCash left off.** A schedule's last occurrence
  and the link from each transaction GnuCash entered for it are imported, so those
  occurrences are neither upcoming nor due again, and the Plan shows them matched.
  They stay settled history and do not appear in Review.
- **Upcoming in the schedule editors.** It lists the next occurrences not yet
  entered, each with every future change applied, including each split's future
  amounts and seasonal months, rather than the first few from the schedule's start.

## Native-book compatibility

No schema change; no migration is needed. The fields involved already exist. A book
imported before this version lacks the GnuCash links, which only the GnuCash book
holds: import it again to add them. Re-import keeps everything set in BreadSched.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a310 needs no
restore; the links imported here are read there as well.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
