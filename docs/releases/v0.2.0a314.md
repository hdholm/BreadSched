# BreadSched 0.2.0a314

Application version: `0.2.0a314`

Native schema version: `13`

Supported native schemas: `6–13`

This alpha fixes three field reports: reconciliation that remembers (#403), undoing a
large step (#405), and Find as a report (#408).

## Highlights

- **Reconcile remembers.** The interest, fees, and other lines you added to recent
  statements come back, ready for this statement's amounts, and the statement date
  starts a month after the last one. Starting a statement already reconciled points
  you at Reopen, and changing a reconciled split asks first.
- **Large undo.** Undoing an import says what it will undo and asks, then shows its
  progress.
- **Find, and Transaction Detail.** Search several accounts at once, nest subtotals
  (account, then month, then description, say; notes too), and print the result.
  On the desktop it is also **Reports → Transaction Detail…**.

## Command-line and browser compatibility

`breadsched find --subtotal` (repeatable) and `subtotal` on `/api/find` nest
subtotals; JSON groups gain `depth` and `children`, and the result `subtotals`. The
reconciliation view gains `default_statement_date` and `remembered_lines`; register
splits gain `reconciled`. `POST /api/v1/undo/preview` is new. Nothing is removed.

## Native-book compatibility

No schema change. Remembered statement lines are book metadata
(`reconcile.lines:<account>`); earlier versions ignore it.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a313 needs no
restore; remembered statement lines are simply not offered there.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
