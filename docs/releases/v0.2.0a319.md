# BreadSched 0.2.0a319

Application version: `0.2.0a319`

Native schema version: `14`

Supported native schemas: `6–14`

This alpha completes decision 0005 (#397): Review groups the actuals waiting for a
decision by category.

## Highlights

- **Review by category.** Actuals waiting in Review are listed under a heading for
  each category (the first expense or income account each was for), with those that
  have none last and each group oldest first, so a month's grocery purchases are
  worked through together. Desktop, browser, and `breadsched review`.

## Command-line and browser compatibility

`/api/review` lists actuals in group order and gives each a `group`;
`breadsched review` prints a heading per group and adds `group` in JSON. Nothing is
removed.

## Native-book compatibility

No schema change.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a318 needs no
restore.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
