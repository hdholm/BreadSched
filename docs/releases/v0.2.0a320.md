# BreadSched 0.2.0a320

Application version: `0.2.0a320`

Native schema version: `14`

Supported native schemas: `6–14`

This alpha makes the book host's user directory cheaper to read.

## Highlights

- **Fewer writes per request.** Each request to a shared book opens the host's user
  directory several times. Every connection used to rerun the directory's whole
  schema script, a small write each time; now it runs only when a table is missing.
  On Windows this is the likeliest cause of requests that occasionally went
  unanswered for 30 seconds.

## Command-line and browser compatibility

No change.

## Native-book compatibility

No schema change. The user directory's tables are unchanged.

## Upgrade and rollback

Keep an independent backup of a real book. Going back to 0.2.0a319 needs no
restore.

## Verified artifacts

After the complete CI matrix succeeds on main, the release workflow publishes a
source distribution, pure-Python wheel, Windows installer, Flatpak bundle, Debian
and Fedora packages, and `SHA256SUMS` for the tested commit.
