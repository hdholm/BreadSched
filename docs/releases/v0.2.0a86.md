# BreadSched 0.2.0a86

Application version: `0.2.0a86`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds a packaged standalone user guide and makes it available offline
from the GTK Help menu.

## Highlights

- **Help → User Guide** and `F1` open the guide in a bounded, scrollable GTK window.
- The same Markdown source ships in the Python package and remains readable directly
  from the source tree.
- The guide covers first use, accounts, registers, reconciliation, schedules, Plan,
  actual resolution, Projection and scenarios, imports, specialized household
  workflows, printing, verification, backup, and recovery.
- The README now concentrates on product orientation, developer setup, invocation,
  project-document links, and essential book safety.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly, and the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Make an independent backup before upgrading. This release does not migrate schema 7
books, so rollback to a BreadSched build that supports schema 7 does not require a
format conversion. Keep using independent storage for backups and do not keep the
only live SQLite book on a synchronized or network filesystem.

## Verified artifacts

The release workflow publishes a source distribution, a pure-Python wheel, and
`SHA256SUMS` from an accepted `main` commit after its complete CI matrix passes.
