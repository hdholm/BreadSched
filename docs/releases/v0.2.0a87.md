# BreadSched 0.2.0a87

Application version: `0.2.0a87`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha makes historical planning suggestions explainable against a named,
versioned inference policy.

## Highlights

- Historical-estimate anomaly thresholds, confidence weights, cadence and trend
  tolerances, seasonal criteria, variability bands, and funding tie-breaks now live
  in one immutable `historical-estimates-v1` policy.
- Structured proposal evidence records the complete applied policy and version;
  accepted drafts retain that provenance, and review explanations show the version.
- An independent, hand-calculated golden book protects spike handling, funding
  selection, monthly anchors, seasonal profiles, trends, and confidence arithmetic.
- Changing an inference policy now requires a separately named version that can be
  rechecked against the same acceptance evidence.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly, and the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Make an independent backup before upgrading. This release does not migrate schema 7
books, so rollback to a BreadSched build that supports schema 7 does not require a
format conversion. Existing accepted estimates retain their prior evidence unchanged;
new suggestions include the versioned rule evidence added by this release.

## Verified artifacts

The release workflow publishes a source distribution, a pure-Python wheel, and
`SHA256SUMS` from an accepted `main` commit after its complete CI matrix passes.
