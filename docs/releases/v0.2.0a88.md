# BreadSched 0.2.0a88

Application version: `0.2.0a88`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha adds the read-only Expense Explorer service contract for application
integrations. Dedicated GTK, web, and printable views are pending.

## Highlights

- Expense categories, period values, and section totals reuse the Plan query.
- Selected category cells expose planned occurrences, actual transactions, and
  temporary groups of actual amounts by trimmed, case-insensitive description.
- Merchant amounts reconcile to the category's actual value. The category plan
  remains unallocated; no merchant budgets or persisted rules are introduced.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly, and the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Make an independent backup before upgrading. This release does not migrate schema 7
books, so rollback to a BreadSched build that supports schema 7 does not require a
format conversion. No book data is changed by an expense query.

## Verified artifacts

The release workflow publishes a source distribution, a pure-Python wheel, and
`SHA256SUMS` from an accepted `main` commit after its complete CI matrix passes.
