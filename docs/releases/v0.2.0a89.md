# BreadSched 0.2.0a89

Application version: `0.2.0a89`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha presents Expense Explorer in GTK and web Plan views.

## Highlights

- Compare category plan and actual values by period with bars and exact-value tables.
- Inspect category trends and merchant actual transactions without merchant budgets.
- Web Plan printing includes the applied explorer selection; GTK **Print…** in
  the Explorer prints the selected category and period with merchant detail.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly, and the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Make an independent backup before upgrading. This release does not migrate schema 7
books, so rollback to a BreadSched build that supports schema 7 does not require a
format conversion. Explorer views do not write to the book.

## Verified artifacts

The release workflow publishes a source distribution, a pure-Python wheel, and
`SHA256SUMS` from an accepted `main` commit after its complete CI matrix passes.
