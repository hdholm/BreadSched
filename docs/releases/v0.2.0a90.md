# BreadSched 0.2.0a90

Application version: `0.2.0a90`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha keeps the Expense Explorer web response in a focused read-only adapter.

## Highlights

- Expense Explorer query translation and response serialization now have one
  presentation-owned module outside the main API class.
- Category and merchant amounts still come from the shared Plan reporting service;
  the existing web route and response are unchanged.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly, and the supported
native compatibility window remains schemas 6–7.

## Upgrade and rollback

Make an independent backup before upgrading. This release does not migrate schema 7
books, so rollback to a BreadSched build that supports schema 7 does not require a
format conversion. The read-only response adapter does not write book data.

## Verified artifacts

The release workflow publishes a source distribution, a pure-Python wheel, and
`SHA256SUMS` from an accepted `main` commit after its complete CI matrix passes.
