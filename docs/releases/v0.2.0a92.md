# BreadSched 0.2.0a92

Application version: `0.2.0a92`

Native schema version: `7`

Supported native schemas: `6–7`

This alpha isolates the read-only web Plan report response in a focused adapter.

## Highlights

- Plan query translation and report serialization now have one presentation-owned
  module outside the main API class.
- Saved controls, scenario comparisons, and category, cash, mortgage, and planning
  flow results still come from the shared Plan service with the existing response.

## Native-book compatibility

No data-format change was made. Schema 7 books open directly; the supported native
compatibility window remains schemas 6–7.

## Upgrade and rollback

Make an independent backup before upgrading. This release does not migrate schema 7
books, so rollback to a BreadSched build that supports schema 7 does not require a
format conversion. The read-only adapter does not write book data.

## Verified artifacts

The release workflow publishes a source distribution, a pure-Python wheel, and
`SHA256SUMS` from an accepted `main` commit after its complete CI matrix passes.
