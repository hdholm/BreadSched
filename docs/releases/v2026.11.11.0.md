# BreadSched 2026.11.11.0

The first beta of BreadSched, a household finance application for tracking your
bank and card accounts, seeing the cash you will have, budgeting with jars,
reporting on where the money goes, and planning years ahead. Use as much of it as
you want: each step is optional. The website, <https://hdholm.github.io/BreadSched/>,
walks through them.

Application version: `2026.11.11.0`
Release stage: beta (a GitHub pre-release)
Native schema version: `14`
Supported native schemas: `13–14`

## What is new since the last alpha

- **Calendar versions.** Versions are now the day a release is prepared
  (`YYYY.M.D.PATCH`), with the stage beside them. This one sorts after every 0.2.0
  alpha, so packages upgrade in place.
- **Breadlets.** Reports, Dashboard items, importers and exporters are plug-ins
  listed and run the same way on the desktop (the **Reports** menu), in the browser
  (**Reports**), and on the command line (`breadsched breadlets`, `breadsched
  report`). New charted reports: **Spending by category** (a ring of where the money
  went) and **Income and spending**. Every chart has its exact values beside it. An
  installed Python package can add its own breadlets.
- **The Dashboard is the home view, made of breadlets.** A book opens on it; its tab
  is pinned first on the desktop. Every item on it (summary figures, a new
  cash-flow chart, groups, bills, income, reimbursables, FSA claims, goals, spending
  this month, income and spending) can be shown or hidden, opens what it is when
  chosen, and its tables sort by any column.
- **One Reports window on the desktop**, each report in its own tab; the Expense
  Explorer is a report in both interfaces.
- **Grouped browser navigation**: Dashboard, Reports, and five menus instead of
  nineteen buttons.
- **Import a date range or chosen accounts**, starting by default at the day you
  last imported the same file.
- **The same words everywhere**: jars for bills, estimates and goals (**In the
  jar**, **Add to jar**, **In goal jars**), the Expense Explorer, and reimbursable
  expenses.
- Simpler issue forms, and Help → Report a Problem fills in your version and system.

The full list is in the [changelog](https://github.com/hdholm/BreadSched/blob/main/CHANGELOG.md).

## Changes to what you do

- **Imports start at your last import.** Importing a file you have imported before
  now starts at the day you last imported it. After editing or reconciling older
  transactions in GnuCash, choose **All dates** (`breadsched import --since all`).
- **A book opens on the Dashboard**, not on the tab you last used; your other tabs
  are still restored behind it.
- `breadsched plugins` is now `breadsched breadlets`.
- In the browser, the net worth history is under **Reports** (the Dashboard's
  **Net worth** figure opens it), and each Dashboard table's chosen columns reset
  once.

## Upgrade and rollback

This version opens books written by 0.2.0a301 and later (native schemas 13 and 14).
A schema 13 book is brought forward to schema 14 when it is first opened for
writing, after a verified backup is written beside it; to roll back, restore that
backup and use the earlier version. A book from an alpha before 0.2.0a301 is
refused with a message saying so: open it once with 0.2.0a321, which brings it
forward, then open it here.

Back up your book before upgrading (**File → Back Up Current Book…** or
`breadsched backup`), and
keep the backup until you are satisfied. Installing over an alpha replaces the
program and keeps your books; uninstalling never removes a book.

## Verified artifacts

The release workflow builds every file from the tested commit of `main` and attaches:

- the wheel and source distribution;
- `BreadSched-2026.11.11.0-setup.exe`, the per-user Windows installer with its own
  Python and GTK runtime, built, installed over the newest published installer,
  exercised, and uninstalled on Windows;
- `BreadSched-2026.11.11.0.flatpak`, built and installed in its sandbox;
- `breadsched_2026.11.11.0_all.deb` and `breadsched-2026.11.11.0-1.noarch.rpm`,
  built and installed on their distributions;
- `SHA256SUMS` covering all of them.

**These files are not yet code-signed.** Windows SmartScreen may warn before the
installer runs. Check each download against `SHA256SUMS` before installing:

```bash
sha256sum --check --ignore-missing SHA256SUMS
```

On Windows PowerShell, compare `Get-FileHash .\BreadSched-2026.11.11.0-setup.exe`
with its line in `SHA256SUMS`.
