# BreadSched 2026.11.25.0

The fifth beta of BreadSched, a household finance application for tracking your
bank and card accounts, seeing the cash you will have, budgeting with jars,
reporting on where the money goes, and planning years ahead. This beta gives the
Windows install BreadSched's own icon and closes a security finding in the browser
server. The website, <https://hdholm.github.io/BreadSched/>, walks through each
step.

Application version: `2026.11.25.0`
Release stage: beta (a GitHub pre-release)
Native schema version: `15`
Supported native schemas: `13–15`

## What is new since 2026.11.22.1

- **BreadSched has its own icon on Windows.** The Start-menu shortcut, the entry in
  Settings > Apps, the installer and uninstaller, and the application window show
  the BreadSched icon, where the shortcut showed Python's.
- **An uploaded document's name may not contain a line break.** Uploading a file
  whose name holds a line break or another control character is refused, and no
  response header the browser server writes can hold one (CodeQL
  `py/http-response-splitting`). No such header was ever sent: the name was always
  encoded.

The full list is in the [changelog](https://github.com/hdholm/BreadSched/blob/main/CHANGELOG.md).

## Upgrade and rollback

This version keeps native schema 15, so it changes nothing in a book that
2026.11.22.1 has opened. A book from 2026.11.22.0 or an earlier beta (schemas 13
and 14) is moved to schema 15 when first opened for writing, after a verified backup
is written beside it (`.pre-migration-v14.bak`). A book from an alpha before
0.2.0a301 is refused with a message saying so: open it once with 0.2.0a321, which
brings it forward, then open it here.

Installing over 2026.11.22.1, an earlier beta, or an alpha replaces the program and
keeps your books; uninstalling never removes a book. Back up your book before
upgrading (**File → Back Up Current Book…** or `breadsched backup`), and keep the
backup until you are satisfied.

To roll back to 2026.11.22.1, install it again: it opens the same books. To roll
back further, to 2026.11.22.0, open the backup written when the book moved to
schema 15 (or your own backup from before then); changes made since the move are
not in that backup.

## Verified artifacts

The release workflow builds every file from the tested commit of `main` and attaches:

- the wheel and source distribution;
- `BreadSched-2026.11.25.0-setup.exe`, the per-user Windows installer with its own
  Python and GTK runtime. It is built, installed over the previous beta's
  installer, exercised (including its Start-menu shortcut, Apps entry, and window
  icon), and uninstalled on Windows;
- `BreadSched-2026.11.25.0.flatpak`, built and installed in its sandbox;
- `breadsched_2026.11.25.0_all.deb` and `breadsched-2026.11.25.0-1.noarch.rpm`,
  built and installed on their distributions;
- `SHA256SUMS` covering all of them.

**These files are not yet code-signed.** Windows SmartScreen may warn before the
installer runs. Check each download against `SHA256SUMS` before installing:

```bash
sha256sum --check --ignore-missing SHA256SUMS
```

On Windows PowerShell, compare `Get-FileHash .\BreadSched-2026.11.25.0-setup.exe`
with its line in `SHA256SUMS`.
