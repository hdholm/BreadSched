# BreadSched 2026.11.28.0

The eighth beta of BreadSched, a household finance application for tracking your
bank and card accounts, seeing the cash you will have, budgeting with jars,
reporting on where the money goes, and planning years ahead. This beta fixes the
Projection for a schedule version that adds or drops a leg, makes the desktop FSA
Dashboard fast and the FSA claims window simpler, fixes the register's
right-click menu, and reports a desktop crash. The website,
<https://hdholm.github.io/BreadSched/>, walks through each step.

Application version: `2026.11.28.0`
Release stage: beta (a GitHub pre-release)
Native schema version: `16`
Supported native schemas: `13–16`

## What is new since 2026.11.27.0

- **The projection works with a schedule version that adds or drops a leg.** A
  schedule whose future change had more or fewer legs than the schedule itself
  stopped the Projection and the Plan with "zip() argument 2 is shorter than
  argument 1"; each occurrence's legs are now planned as they are.
- **The FSA Dashboard no longer freezes while it reads.** Proposing claim links
  reread every claim for each FSA statement line, which took seconds on a long FSA
  history and could bring up the not-responding prompt; claims are read once now.
  The first time the dashboard is shown it says **Loading…** while it reads in the
  background, and when it reads again its old figures are greyed under
  **Updating…**.
- **Proposed claim links stay near an FSA year.** Only FSA statement lines within,
  or within 30 days of, one of their account's funding years are proposed, so lines
  from years before any FSA year was set up no longer appear.
- **One Edit FSA Claims command.** It opens the claim selected on the FSA Dashboard,
  or the claims window as it opens anywhere; Edit FSA Claim and Manage FSA Claims
  are gone.
- **The FSA claims window is simpler.** A **Claim** tab holds what most claims need;
  the EOB change note, a payer covering part, provider refunds, repayments, rejected
  attempts, the history, and closing are on an **Advanced** tab that counts what it
  holds. Reimbursements and repayments collapse like the other lists, **Payer covers
  part** says why it offers only None, and double-clicking a transaction adds or
  removes it.
- **The register's right-click menu always has the transaction's commands.** A
  right-click on the cell being edited showed the text field's Cut, Copy, Paste, and
  Delete instead.
- **Fewer register commands in the Actions menu.** Edit Transaction in Place and
  Enter Transaction are gone; Cancel Transaction stays.
- **Preferences → Dashboard → Groups no longer has Suggest from accounts**, which
  only removed every group.
- **A desktop crash is reported.** When BreadSched closes on its own, where it was is
  written to a crash log, and the next start offers **Report problem…** with the
  start of that log filled in, as it does after a freeze.

The full list is in the [changelog](https://github.com/hdholm/BreadSched/blob/main/CHANGELOG.md).

## Upgrade and rollback

This version keeps native schema 16, so it changes nothing in a book that
2026.11.27.0 has opened. A book from 2026.11.25.0 or 2026.11.22.1 (schema 15), or
from an earlier beta (schemas 13 and 14), is moved to schema 16 when first opened for
writing, after a verified backup is written beside it (`.pre-migration-v15.bak` for
a schema-15 book). That move keeps each schedule's future, per-leg, seasonal, and
one-time amounts as versions with the same amounts; a seasonal month amount now keeps
applying after a later whole-schedule amount change. A book from an alpha before
0.2.0a301 is refused with a message saying so: open it once with 0.2.0a321, which
brings it forward, then open it here.

Installing over 2026.11.27.0, an earlier beta, or an alpha replaces the program and
keeps your books; uninstalling never removes a book. Back up your book before
upgrading (**File → Back Up Current Book…** or `breadsched backup`), and keep the
backup until you are satisfied.

To roll back to 2026.11.27.0, install it again: it opens the same books. To roll back
further, to 2026.11.25.0 or earlier, open the backup written when the book moved to
schema 16 (or your own backup from before then); changes made since the move are not
in that backup.

## Verified artifacts

The release workflow builds every file from the tested commit of `main` and attaches:

- the wheel and source distribution;
- `BreadSched-2026.11.28.0-setup.exe`, the per-user Windows installer with its own
  Python and GTK runtime. It is built, installed over the previous beta's
  installer, exercised (including its Start-menu shortcut, Apps entry, and window
  icon), and uninstalled on Windows;
- `BreadSched-2026.11.28.0.flatpak`, built and installed in its sandbox;
- `breadsched_2026.11.28.0_all.deb` and `breadsched-2026.11.28.0-1.noarch.rpm`,
  built and installed on their distributions;
- `SHA256SUMS` covering all of them.

**These files are not yet code-signed.** Windows SmartScreen may warn before the
installer runs. Check each download against `SHA256SUMS` before installing:

```bash
sha256sum --check --ignore-missing SHA256SUMS
```

On Windows PowerShell, compare `Get-FileHash .\BreadSched-2026.11.28.0-setup.exe`
with its line in `SHA256SUMS`.
